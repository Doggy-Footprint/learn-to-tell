읽기 쉬우면 왜 더 믿게 될까?

작업: agent가 쓴 답변과 문서를 읽고 맞는지 판단해야 한다. 결정 변수: 무엇을 근거로 믿을지 (처리 유창성인가, 검증 가능한 근거인가).

먼저 예측

아래 네 카드는 같은 주장을 모양만 바꿔 보여 준다고 하자. 사람들의 "그럴듯함" 평가는 어떻게 될까?

직접 평가하기 내 응답

카드마다 "얼마나 그럴듯한가"를 0–100으로 매긴다.

0점, 표면만 바꿨는데 내 평가가 벌어진 폭

연구 방향(효과 크기는 과제마다 달라 숫자를 싣지 않는다): 대비 높음 → 참 판단 증가 반복 → 타당 평가 증가 전문 용어 → 심오하다는 평가 개인 한 번의 평가는 노이즈가 크다. 위 효과는 집단 평균에서 보고된 경향

agent 답변에서는? 같은 내용, 다른 문체

질문: "이 마이그레이션을 운영 중에 돌려도 되나?" 아래 세 답은 똑같이 검증되지 않은 주장이다.

낮음읽는 동안의 확신 느낌 (방향만, 수치 아님)
0건바뀐 검증 근거

실사용: 주장을 읽는 순서를 "근거 확인 → 문체"로 뒤집는다. 실행해 보기, 로그, 출처 같은 확인 가능한 것에 점수를 준다. 주의 읽기 쉬움은 오히려 틀린 답을 놓치게 만든다. 거친 문체라도 맞을 수 있다.

한 줄 정리: 매끈함은 맞다는 증거가 아니라 읽기 쉬웠다는 증거다. 믿기 전에 "실행·출처로 확인했나"를 묻는다.
