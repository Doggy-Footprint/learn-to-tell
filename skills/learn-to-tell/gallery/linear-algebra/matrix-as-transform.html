행렬은 공간을 어떻게 바꾸는가?

작업: 모델 레이어나 그래픽 변환의 행렬을 읽고 "이 연산이 데이터에 무슨 짓을 하는지" 판단해야 한다. 결정 변수: 행렬의 열(기저 벡터의 도착점), det(면적 배율), 곱 순서.

먼저 예측 모델로 계산한 예시

행렬 을 적용하면 단위 정사각형()은 어떤 모양이 되는가? 힌트

행렬을 직접 바꿔 보기 모델로 계산한 예시

0배 = |det|

첫째 열 = î가 가는 곳, 둘째 열 = ĵ가 가는 곳.

범위 근거: 슬라이더 -2~2는 격자가 화면(±8)을 벗어나지 않게 고른 표시용 범위다. 회전 30°는 cos=0.866, sin=0.5를 소수 둘째 자리로 반올림했다(det≈1.0).

행렬 곱 = 변환 합성: AB와 BA는 같은가? 모델로 계산한 예시

(가로 2배), (90° 회전). 는 B를 먼저, 는 A를 먼저 적용한다.

AB (B → A)

BA (A → B)

실제 활용과 주의

  • 활용: 신경망 선형 레이어 는 입력 공간의 변환이다. 그래픽스의 회전·스케일·전단도 같은 2×2/3×3 행렬이다.
  • 주의: det=0이면 평면이 선으로 찌부러진다. 한 번 잃은 방향 정보는 돌릴 수 없어 역행렬이 없다. det가 0에 가까우면 역행렬이 있어도 수치적으로 불안정하다.
  • 주의: det<0이면 면적은 그대로여도 방향이 뒤집힌다(거울상).

한 줄 정리: 행렬의 열은 기저 벡터의 도착점이고, |det|는 면적 배율이며, AB는 오른쪽 B부터 적용한다.
