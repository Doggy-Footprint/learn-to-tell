작업

막힌 결정
의존성 버전 범위 (^ / ~ / 고정)
진단
  1. 1패키지 버전
  2. 2semver (주.부.수) 알고 있음
  3. 3^와 ~ 범위 애매함
  4. 4lockfile이 미치는 범위 아예 모름
경로
규칙만 알면 되고 조작해서 관찰할 것이 없다 → 3단계를 건너뛴다.
대화 자료와 퀴즈 예시

agent · 자료^1.2.3은 2.0.0 미만, ~1.2.3은 1.3.0 미만까지 허용한다. 단, ^0.2.3은 0.3.0 미만만 허용한다. package-lock.json은 배포되지 않는다(npm 기준). 그래서 라이브러리를 설치하는 쪽은 package.json의 범위 안에서 버전을 새로 고른다.

agent · 퀴즈 1 (질문 만들기)이 결정을 agent에게 맡기기 전에 꼭 물어볼 질문 하나를 써 주세요.

agent · 퀴즈 2 (선택과 의미)이 라이브러리에 ^를 쓸지 정확한 버전으로 고정할지 고르고, 그 선택을 바꿀 조건을 한 문장으로 써 주세요.
