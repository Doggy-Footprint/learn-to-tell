시나리오와 수업 예시

작업 상황마다 스킬이 어떤 경로로 어떤 자료를 내는지 보는 예시들이다. 새 수업은 아래 라이브러리의 부품을 조합해 빈 파일에서 짠다. 예시 수업은 조합 방법을 보여 줄 뿐, 복사해 고치는 템플릿이 아니다.

스킬의 흐름과 갈림길

0 시작→ 1 진단 (대화)→ 2 범위→ 3 자료→ 4 서술 퀴즈 (대화)→ 5 작업 복귀→ 6 지식 map
시뮬레이션 경로 — 조작하며 관찰할 것이 있으면 kit 부품으로 lesson.html을 짠다. (아래 예시 수업) simple 경로 — 관찰할 것이 없으면 3단계를 건너뛰고 대화 안의 짧은 자료와 퀴즈로 끝낸다. (6) 진단만 — 사다리 맨 위 단까지 알고, 확인 퀴즈도 통과하면 학습 없이 기록만 남긴다. (7) 회차 분할 — 자료가 20분을 넘으면 알리고 나눈다. (8)

6. 라이브러리의 의존성 버전 범위

작업
배포할 npm 라이브러리의 package.json 정리
막힌 결정
의존성 버전 범위 (^ / ~ / 고정)
진단
  1. 1패키지 버전
  2. 2semver (주.부.수) 알고 있음
  3. 3^와 ~ 범위 애매함
  4. 4lockfile이 미치는 범위 아예 모름
경로
규칙만 알면 되고 조작해서 관찰할 것이 없다 → 3단계를 건너뛴다.
대화 자료와 퀴즈 예시

agent · 자료^1.2.3은 2.0.0 미만, ~1.2.3은 1.3.0 미만까지 허용한다. 단, ^0.2.3은 0.3.0 미만만 허용한다. package-lock.json은 배포되지 않는다(npm 기준). 그래서 라이브러리를 설치하는 쪽은 package.json의 범위 안에서 버전을 새로 고른다.

agent · 퀴즈 1 (질문 만들기)이 결정을 agent에게 맡기기 전에 꼭 물어볼 질문 하나를 써 주세요.

agent · 퀴즈 2 (선택과 의미)이 라이브러리에 ^를 쓸지 정확한 버전으로 고정할지 고르고, 그 선택을 바꿀 조건을 한 문장으로 써 주세요.
