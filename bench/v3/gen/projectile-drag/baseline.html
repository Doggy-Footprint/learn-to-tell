공기저항이 있으면 최적 발사각은 얼마나 낮아질까?

sin2θ 공식에서 출발해 공 던지기 게임에 바로 넣을 수 있는 코드까지. 아래 숫자는 모두 이 페이지가 브라우저에서 직접 적분해서 계산한 값입니다.

짧은 답: 하나의 수치로 정해지지 않습니다. 발사 속도 v₀와 종단속도 vt의 비율에 따라 달라집니다. v₀가 vt보다 훨씬 작으면 거의 45°이고, v₀ ≈ vt면 40°를 조금 넘는 정도, v₀가 vt의 몇 배가 되면 30° 근처나 그보다 낮게 내려갑니다. 게임 감각으로 말하면 "세게 던질수록, 가벼운 공일수록 최적각이 낮아진다"입니다.

1. 출발점: 진공에서는 왜 45°인가

아는 내용을 짧게 정리합니다. 진공에서 지면에서 쏘면

R = v₀² sin2θ / g

sin2θ는 θ = 45°에서 최대입니다. 이 결과에는 대칭 하나가 깔려 있습니다. 올라가는 시간과 내려오는 시간이 같고, 수평 속도는 끝까지 그대로입니다. 각을 높이면 체공 시간을 얻는 대신 수평 속도를 잃는데, 그 둘이 정확히 맞바뀌는 지점이 45°입니다.

공기저항은 이 대칭을 깹니다. 그래서 45°라는 답도 함께 사라집니다.

2. 공기저항 모델: 속도의 제곱

공 정도 크기와 속도(야구공, 테니스공, 수류탄)에서는 항력이 속도의 제곱에 비례합니다. 방향은 속도와 반대입니다.

Fdrag = −½ ρ Cd A |v| v  ⇒  a = g − k |v| v,   k = ρCdA / (2m)

파라미터를 하나로 묶는 게 핵심입니다. 공을 떨어뜨리면 항력이 중력과 같아지는 속도에서 더 이상 가속하지 않습니다. 이것이 종단속도입니다.

k vt² = g  ⇒  vt = √(g/k)

이렇게 하면 k 대신 직관적인 "m/s" 단위 하나로 공의 성질을 표현할 수 있습니다. 대략의 값은 다음과 같습니다.

물체종단속도 vt (대략)
탁구공~9 m/s
배드민턴 셔틀콕~7 m/s
테니스공~20–25 m/s
야구공~35–40 m/s
포환(쇠공)~100 m/s 이상

공기 밀도, 표면, 회전 등에 따라 달라지는 대략값입니다. 게임에서는 "느낌이 맞는" 값으로 튜닝하면 됩니다.

왜 비율 하나로 충분한가: 속도를 vt로, 길이를 vt²/g로, 시간을 vt/g로 나누면 운동방정식에서 g와 k가 모두 사라집니다. 남는 변수는 v₀/vt 하나뿐입니다. 따라서 최적각은 θ*(v₀/vt)라는 곡선 하나로 완전히 정해집니다.

3. 왜 낮아지는가: 직관

  1. 오래 떠 있으면 손해가 커진다. 항력은 비행 내내 수평 속도를 깎습니다. 높게 쏘면 체공 시간은 늘지만, 그 시간 동안 수평 속도는 계속 줄어듭니다. 체공 시간의 가치가 진공일 때보다 떨어집니다.
  2. 빠를 때 손해가 가장 크다. 항력은 v²에 비례하므로 발사 직후 손실이 압도적입니다. 처음 속도의 수평 성분을 최대한 살려 두는 쪽, 즉 낮은 각이 유리해집니다.
  3. 궤적이 비대칭이 된다. 올라갈 때는 길고 완만하게, 내려올 때는 짧고 가파르게 떨어집니다. 꼭짓점이 착지점 쪽으로 쏠립니다. 이 비대칭이 게임에서 "진짜 같은" 느낌을 만듭니다.

4. 직접 해보기

슬라이더를 움직이세요. 매번 0.1° 간격으로 모든 각도를 시뮬레이션해서 사거리가 가장 긴 각도를 찾습니다.

회색 점선 = 진공 45°  ·  빨강 = 공기저항 있는 최적각  ·  파랑 = 내 발사각

v₀/vt에 따른 최적각 곡선

지면 발사(높이 0) 기준. 표 값은 이 페이지가 RK4 적분(dt = 비행시간의 약 1/2000)으로 계산합니다.

5. 한 걸음 더: 같이 영향을 주는 것들

  • 발사 높이. 진공에서도 손 높이에서 던지면 최적각은 45°보다 낮습니다. 공기저항과 같은 방향으로 작용해서 효과가 겹칩니다. 위 시뮬레이터에서 발사 높이를 올려 확인해 보세요. 캐릭터가 어깨 높이에서 던진다면 이 효과를 무시하면 안 됩니다.
  • 사거리 손실. 최적각을 써도 사거리는 진공보다 크게 줄어듭니다. v₀ = vt이면 대략 진공의 절반 남짓입니다. 각도 변화보다 이쪽이 플레이어 체감에 훨씬 큽니다.
  • 최적점은 평평하다. 최적각 근처 ±5°에서는 사거리가 몇 %밖에 변하지 않습니다. 정확한 각도가 플레이어에게 보이지는 않지만, 궤적 모양은 보입니다.
  • 회전(마그누스 효과). 백스핀은 양력을 만들어 최적각을 더 낮춥니다. 골프 드라이버 발사각이 10°대인 이유입니다. 여기서는 다루지 않습니다.
  • 선형 항력 (a = g − c·v). 아주 느리거나 작은 물체 모델입니다. 해석해가 있어서 편하지만 공 던지기에는 맞지 않습니다. 이 경우에도 최적각은 45°보다 낮아집니다.

6. 게임 코드로 옮기기

제곱 항력은 해석해가 없어서(정확히는 다루기 힘든 형태) 수치 적분해야 합니다. 게임에서는 프레임마다 적분하므로 사실 진공보다 코드가 한 줄 늘 뿐입니다.

// 파라미터: 디자이너가 만지기 쉬운 형태로 노출
const g  = 9.81;
const vt = 30;            // 종단속도 [m/s] — "공의 가벼움"
const k  = g / (vt * vt); // 항력 계수

function accel(vx, vy) {
  const s = Math.hypot(vx, vy);
  return [-k * s * vx, -g - k * s * vy];
}

// 고정 타임스텝 (예: 1/120 s), semi-implicit Euler
function step(b, dt) {
  const [ax, ay] = accel(b.vx, b.vy);
  b.vx += ax * dt;  b.vy += ay * dt;   // 속도 먼저
  b.x  += b.vx * dt; b.y += b.vy * dt; // 갱신된 속도로 위치
}

실전 체크리스트

  • 고정 타임스텝을 쓰세요. 가변 dt로 적분하면 프레임레이트에 따라 사거리가 달라집니다. 멀티플레이나 리플레이에서 결과가 어긋납니다.
  • Euler라면 dt를 작게 잡으세요. semi-implicit Euler에 dt = 1/60이면 k·|v|·dt ≪ 1일 때 충분합니다. 아주 가벼운 공(작은 vt)을 빠르게 쏘면 k|v|dt가 커져 불안정해질 수 있습니다. 서브스텝을 나누거나 RK4를 쓰세요.
  • 착지점은 보간하세요. y가 음수가 된 프레임에서 직전 위치와 선형 보간하면 dt에 덜 민감한 착지점을 얻습니다.
  • 조준 보조 / AI 투척. "목표 거리 D에 맞는 각도"는 공식으로 못 구합니다. 같은 step 함수로 오프라인 시뮬레이션을 돌린 뒤 이분 탐색하거나, (v₀/vt, 각도) → 사거리 표를 미리 구워 두세요. 궤적 미리보기 점선도 반드시 같은 적분기와 같은 dt로 그려야 실제 궤적과 일치합니다.
  • 무차원화를 활용하세요. 사거리 표는 v₀/vt에 대해서만 만들면 됩니다. 실제 거리는 결과에 vt²/g를 곱해서 얻습니다. 공 종류마다 표를 따로 만들 필요가 없습니다.
최적각 탐색 코드 (이 페이지가 쓰는 것) 
function range(v0, deg, vt, h0 = 0) {
  const k = g / (vt * vt), th = deg * Math.PI / 180;
  let x = 0, y = h0, vx = v0 * Math.cos(th), vy = v0 * Math.sin(th);
  const dt = /* 예상 비행시간 / 2000 */;
  while (true) {
    const px = x, py = y;
    [x, y, vx, vy] = rk4(x, y, vx, vy, dt);
    if (y < 0 && vy < 0) return px + (x - px) * py / (py - y); // 보간
  }
}
// 0.1° 간격 전수 탐색 → 최대 사거리 각도

7. 확인 문제

요약

  • 제곱 항력에서 최적각은 v₀/vt 하나로 정해집니다.
  • v₀ ≪ vt이면 약 45°, v₀ ≈ vt이면 40°대 초반, v₀가 vt의 몇 배면 30° 근처나 그 아래입니다. 정확한 값은 위 표를 보세요.
  • 원인: 체공 시간 동안 수평 속도를 잃고, 항력은 빠른 초반에 가장 셉니다.
  • 게임에서는 vt를 튜닝 파라미터로 노출하고, 고정 dt로 적분하고, 조준 보조는 같은 적분기로 시뮬레이션하세요.
