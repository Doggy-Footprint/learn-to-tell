# 운동역학 · 충격량과 지면반력(선운동역학)
## 상황
- 작업: 스마트워치의 케이던스·지면 접촉 시간(GCT)으로 착지 부하를 추정하는 러닝 코칭 기능을 설계한다. 학습 자료를 만들어 달라.
- 배경: 앱 개발자. 센서 값(케이던스 spm, GCT ms, 수직 진동 cm)은 읽을 수 있으나 힘·충격량·운동량의 관계를 배운 적이 없다.
## 진단 결과(고정)
- 사다리(낮은 단부터): 힘과 무게(N, 체중 배수 BW)(알고 있음) → 운동량 p=mv(애매함) → 충격량=∫F dt=Δp(아예 모름) → 한 걸음 평균 수직력=mg·걸음시간/GCT(아예 모름) → 지면반력 곡선 형태(충격 피크·능동 피크)(아예 모름)
- 학습 수준: 운동량 ~ 한 걸음 평균 수직력
- 오개념: "접촉 시간이 짧을수록 발이 땅에 덜 머무니까 몸에 가는 부하도 작다"라고 답했다.

## 그림
### F1 달리기 한 걸음 타임라인(접촉-체공)
- 보여 주는 것: 70 kg 주자, 3.5 m/s, 케이던스 170 spm. 한 걸음 0.353 s 중 접촉 0.250 s, 체공 0.103 s를 막대 두 칸과 그 위 측면 실루엣(착지·중간 지지·이지·체공 4자세)으로 보여 준다.
- 속성:
  - P1 [Q] 가로축 시간 0–0.353 s, 1 px당 동일 시간 척도, 접촉/체공 경계 0.250 s — 필수, 이후 모든 계산의 분모가 된다
  - P2 [G] 실루엣 발 위치가 접촉 칸 동안 지면선에 붙고 체공 칸에서 떨어진다 — 필수, 시간 칸과 자세의 대응
  - P3 [T] 0.353 s 한 걸음을 1/4 속도로 반복 재생, 현재 시각 커서 표시 — 선택, 리듬 감각
  - P4 [X] "걸음 시간 = 60/케이던스 = 0.353 s" 문구 — 필수, 케이던스와 시간의 변환식
  - P5 [E] 접촉 칸을 강조색, 체공 칸은 회색 — 필수, 힘이 존재하는 구간이 먼저 보이게
### F2 GCT 두 조건 예측 카드
- 보여 주는 것: 같은 주자·같은 케이던스에서 GCT 200 ms와 300 ms 두 실루엣과 빈 힘 막대. 학습자가 어느 쪽 최대 수직력이 큰지 고른 뒤 막대가 2.78 BW / 1.85 BW로 채워진다(반사인 모델).
- 속성:
  - P1 [I] 선택 전에는 막대 값 숨김, 선택 후 공개 — 필수, predict 장면의 약속
  - P2 [Q] 피크 = (π/2)·mg·0.353/GCT, BW 단위 0–3 BW 공통 척도 — 필수, 두 조건 비교가 정확해야 한다
  - P3 [X] "반사인 근사 모델" 표기 — 필수, 단순화 표시
  - P4 [E] 오개념 선택 시 "짧은 접촉 = 더 큰 힘" 문구를 크게 — 선택, 오개념 직면
### F3 운동량과 충격량 정의도
- 보여 주는 것: 질량 70 kg 블록에 아래 방향 속도 화살표(착지 직전 수직속도 −0.50 m/s)와 이지 시 +0.50 m/s 화살표, 그 사이 위쪽 힘 화살표 F와 시간 Δt. Δp = 70 kg × 1.0 m/s = 70 N·s(중력 제외 순 충격량).
- 속성:
  - P1 [Q] 속도 화살표 길이 ∝ m/s(1 m/s = 80 px), 힘 화살표는 별도 척도 — 필수, 다른 물리량 척도 분리 표시
  - P2 [G] 속도 화살표는 수직, 들어오는/나가는 방향이 반대 — 필수, 운동량 변화가 부호 반전임을 보이기
  - P3 [X] 식 "J = ∫F dt = Δp" 와 단위 N·s = kg·m/s — 필수, 정의
  - P4 [S] 왼쪽 착지 전, 가운데 접촉, 오른쪽 이지 후 3단 구성 — 필수, 시간 순서
### F4 수직 지면반력-시간 곡선과 넓이
- 보여 주는 것: 가로 0–250 ms, 세로 0–3 BW 수직 지면반력 곡선(반사인, 피크 2.22 BW). 곡선 아래 넓이를 채우고, 1 BW 수평선(체중)을 그어 그 위 넓이(순 충격량)와 전체 넓이(242 N·s)를 구분한다.
- 속성:
  - P1 [Q] F(t)=Fmax·sin(πt/GCT), Fmax=2.22 BW, mg=686.7 N — 필수, 수치가 실제 계산과 일치
  - P2 [Q] 전체 넓이 = mg×0.353 s = 242 N·s 숫자 표시 — 필수, 한 걸음 동안 중력 충격량과 같다
  - P3 [G] 1 BW 선 위 넓이와 체공 구간의 1 BW 아래 "빚" 넓이가 같다 — 필수, 수직 운동량 보존의 시각적 근거
  - P4 [I] 곡선 위 커서 이동 시 해당 시각까지의 누적 넓이(N·s)와 수직속도 표시 — 선택, 넓이=속도 변화 체감
  - P5 [E] 넓이 채움이 곡선선보다 먼저 눈에 띄게 — 필수, 핵심은 넓이
### F5 평균력 계산 단계 막대
- 보여 주는 것: 4단계로 쌓이는 막대: ① 걸음 시간 0.353 s ② 충격량 242 N·s(같은 넓이 직사각형) ③ 접촉 0.250 s로 폭을 좁히면 높이 970 N = 1.41 BW ④ 반사인으로 바꾸면 피크 2.22 BW.
- 속성:
  - P1 [T] 단계 버튼마다 직사각형이 넓이를 유지한 채 폭이 줄고 높이가 커지는 변형 — 필수, 넓이 보존 = 충격량 고정
  - P2 [Q] 넓이 수치를 각 단계에 고정 표시 242 N·s — 필수, 불변량 강조
  - P3 [X] 단계별 식 한 줄 — 필수
  - P4 [S] 세로축 BW 척도 0–3 고정 — 필수, 단계 간 높이 비교
### F6 케이던스·GCT 탐색기
- 보여 주는 것: 슬라이더 케이던스 150–190 spm, GCT 180–320 ms. F4 형태 곡선이 즉시 갱신되고 피크 BW, 평균 BW, 체공 시간을 표시. 목표: 피크 ≤ 2.0 BW이면서 체공 ≥ 0 ms.
- 속성:
  - P1 [I] 두 슬라이더, 불가능 조합(GCT > 걸음 시간)은 슬라이더 범위 밖 처리하고 경고 — 필수, 그림이 사실만 보여야 함
  - P2 [Q] 피크 = (π/2)·(60/cadence)/GCT BW — 필수
  - P3 [E] 2.0 BW 목표선과 달성 시 곡선 색 변화 — 필수, 목표 판정
  - P4 [X] "모델: 반사인, 수평력·충격 피크 무시" — 필수, 단순화 표시
  - P5 [G] 케이던스를 올리면 같은 GCT에서 피크가 낮아지는 방향 관계 — 필수, 앱 코칭 근거
### F7 착지 방식 비교 지면반력
- 보여 주는 것: 같은 축(0–250 ms, 0–3 BW)에 뒤꿈치 착지(약 30 ms에 충격 피크 1.6 BW, 약 110 ms에 능동 피크 2.4 BW)와 앞꿈치 착지(충격 피크 없음, 능동 피크 2.4 BW) 두 곡선. 두 곡선 아래 넓이는 동일.
- 속성:
  - P1 [Q] 두 곡선의 넓이 동일하도록 생성, 넓이 수치 표시 — 필수, 착지 방식이 충격량을 바꾸지 않음
  - P2 [Q] 초기 50 ms 부하율(BW/s) 수치: 뒤꿈치 약 53 BW/s, 앞꿈치 약 25 BW/s — 필수, 차이는 부하율에 있다
  - P3 [E] 0–50 ms 구간 확대 강조 — 필수, 핵심 차이 위치
  - P4 [X] "대표 형태, 개인차 큼" 표기 — 필수, 단순화 표시
### F8 퀴즈 센서 카드
- 보여 주는 것: 세 주자 카드(케이던스/GCT: 160/280, 175/230, 185/210). 학습자가 피크 BW가 가장 큰 주자를 고르고, 공개 시 각 카드에 미니 F4 곡선과 피크 값(1.92, 2.34, 2.43 BW)이 나타난다.
- 속성:
  - P1 [Q] 피크는 F6 공식과 동일 계산 — 필수, 일관성
  - P2 [I] 선택 후 공개 — 필수
  - P3 [S] 세 카드 동일 축 척도 — 필수, 비교 가능성
