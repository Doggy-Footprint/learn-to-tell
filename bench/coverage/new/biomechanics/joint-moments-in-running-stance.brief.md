# 운동역학 · 달리기 지지기의 관절 모멘트(지면반력 벡터와 모멘트 팔)
## 상황
- 작업: 스마트워치 데이터로 오버스트라이드(과보폭)를 감지해 무릎 부하 경고를 띄우는 기능을 설계한다. 학습 자료를 만들어 달라.
- 배경: 앱 개발자. 케이던스·GCT는 알지만 힘이 관절에 회전 효과를 만드는 원리와 신체 분절 모델을 처음 접한다.
## 진단 결과(고정)
- 사다리(낮은 단부터): 힘은 크기와 방향을 가진다(알고 있음) → 토크=힘×수직 거리(애매함) → 지면반력 벡터는 압력중심에서 시작해 몸 쪽을 향한다(아예 모름) → 관절 모멘트 ≈ GRF×관절까지의 수직 거리(아예 모름) → 착지 위치(질량중심 앞 거리)가 무릎 모멘트를 바꾼다(아예 모름)
- 학습 수준: 토크 ~ 착지 위치와 무릎 모멘트
- 오개념: "무릎 부하는 지면반력 크기로 정해지니까 힘만 줄이면 된다"라고 답했다.

## 그림
### F1 측면 하지 막대 모형과 GRF 벡터
- 보여 주는 것: 오른쪽 진행 방향 측면도. 70 kg 주자(다리 길이 0.90 m)의 골반(고관절)·무릎·발목·발 4분절 막대, 각 관절 원. 압력중심에서 시작하는 GRF 화살표(중간 지지 시 수직 2.2 BW = 1510 N).
- 속성:
  - P1 [G] 분절 길이 비율 대퇴 0.245·하퇴 0.246·발 0.152(신장 대비, 신장 1.75 m), 화면 1 m = 300 px 동일 축척 — 필수, 몸 비율이 실제와 대응
  - P2 [Q] GRF 화살표 길이 1 BW = 60 px, 공간 축척과 별도 범례 — 필수, 힘과 길이 척도 분리
  - P3 [G] GRF 작용선을 몸 위로 점선 연장 — 필수, 모멘트 팔을 읽을 기준선
  - P4 [X] "2D 시상면 단순화, 근육 미표시" — 필수, 단순화 표시
  - P5 [E] GRF 화살표가 가장 굵고 진한 색 — 필수, 핵심 요소
### F2 두 착지 위치 예측
- 보여 주는 것: F1 모형 두 개. 발이 질량중심 수직선 앞 0.30 m(무릎 거의 편 상태, 굴곡 10°)와 0.10 m(굴곡 25°)에서 착지 순간. 학습자가 무릎 모멘트가 큰 쪽을 고른 뒤 모멘트 팔과 값을 공개.
- 속성:
  - P1 [I] 선택 전 모멘트 팔 숨김 — 필수
  - P2 [Q] 착지 직후 GRF 1.6 BW(1100 N), 뒤로 기울기: 0.30 m 쪽 15°, 0.10 m 쪽 5° — 필수, 착지 위치에 따른 제동 방향
  - P3 [G] 무릎에서 GRF 작용선까지 수선과 길이(cm) 표시 — 필수
  - P4 [X] 두 결과 수치 N·m 표시 — 필수
### F3 토크 정의 렌치
- 보여 주는 것: 볼트 중심에 렌치, 손잡이 끝에 100 N 힘. 힘 방향 핸들을 돌리면 수직 거리 d와 τ = F·d가 바뀐다(손잡이 0.25 m, 수직일 때 25 N·m, 30°일 때 12.5 N·m).
- 속성:
  - P1 [I] 힘 방향 드래그 핸들 0–180° — 필수, 거리가 '수직 거리'임을 체감
  - P2 [G] 회전축에서 작용선까지 직각 표시가 있는 수선 — 필수
  - P3 [Q] τ = F·r·sinθ 실시간 값 — 필수
  - P4 [E] 수선 d를 강조색 — 필수, 핵심 개념
### F4 지지기 GRF 벡터 연속도(나비 그림)
- 보여 주는 것: 측면도에서 0.25 s 지지기를 10 ms 간격으로 GRF 화살표 26개를 압력중심(뒤꿈치→앞꿈치 이동 0.18 m)에서 겹쳐 그린 부채꼴. 초기에 뒤로(제동), 후기에 앞으로(추진) 기운다.
- 속성:
  - P1 [Q] 수평 성분 최대 ±0.45 BW, 수직 최대 2.4 BW, 대표 데이터 형태 — 필수
  - P2 [G] 압력중심이 발바닥 위에서 앞으로 이동 — 필수
  - P3 [T] 화살표가 순서대로 그려지는 애니메이션, 반복 — 선택
  - P4 [X] "제동" / "추진" 라벨과 전환점(약 50% 지지) — 필수
  - P5 [X] "대표 곡선 기반 재구성" 표기 — 필수
### F5 관절 모멘트 이동 단계
- 보여 주는 것: 착지·중간 지지·이지 3자세의 F1 모형. 각 자세에서 GRF와 고관절·무릎·발목까지 모멘트 팔, 관절별 모멘트 막대(N·m/kg): 착지 무릎 1.2, 중간 지지 무릎 2.6·발목 2.3, 이지 발목 2.8·무릎 0.8.
- 속성:
  - P1 [T] 단계 버튼으로 자세 전환, 분절이 보간 이동 — 필수
  - P2 [Q] 모멘트 = GRF×모멘트 팔(분절 관성 무시 근사), 막대 0–3 N·m/kg 공통 척도 — 필수
  - P3 [E] 각 단계에서 가장 큰 관절 모멘트를 강조 — 필수, 부하가 무릎→발목으로 옮겨 감
  - P4 [X] "정적 근사: 분절 질량·가속 무시, 실제 역동역학 값과 ±15%" — 필수, 단순화 표시
### F6 착지 위치 탐색기
- 보여 주는 것: 중간 지지 직전 자세의 F1 모형. 발을 질량중심 기준 −0.05~+0.35 m로 끄는 핸들, 무릎 굴곡 5–40° 슬라이더. GRF 방향은 발→질량중심을 향하도록 자동 계산, 무릎 모멘트 실시간 표시. 목표: 1.6 BW에서 무릎 모멘트 ≤ 120 N·m.
- 속성:
  - P1 [I] 발 드래그 핸들, 굴곡 슬라이더 — 필수
  - P2 [G] GRF 작용선이 질량중심을 지나도록 제약 — 필수, 실제 달리기의 근사 관계
  - P3 [Q] 무릎 모멘트 = 1100 N × 무릎–작용선 수직 거리, N·m 및 N·m/kg — 필수
  - P4 [E] 목표 달성 시 모멘트 팔 색 변화 — 필수
  - P5 [X] 현재 케이던스 환산 힌트 "발 위치를 당기려면 케이던스 +5–10%" — 선택, 앱 연결
### F7 오버스트라이드 비교
- 보여 주는 것: 같은 GRF 크기(1100 N)에서 발 위치 0.30 m vs 0.10 m 두 모형을 나란히. 무릎 모멘트 팔 0.12 m vs 0.05 m → 132 N·m vs 55 N·m, 제동 수평 성분 0.41 BW vs 0.14 BW.
- 속성:
  - P1 [S] 두 패널 동일 축척·동일 질량중심 높이 정렬 — 필수, 비교 가능성
  - P2 [Q] 수치 쌍 표시 — 필수
  - P3 [E] 화살표 크기는 같고 모멘트 팔만 다름을 강조 — 필수, 오개념 반박 핵심
### F8 모멘트 팔 찾기 퀴즈
- 보여 주는 것: 중간 지지 F1 모형에 후보 선분 4개(무릎→발 거리, 무릎→압력중심 수평 거리, 무릎→작용선 수선, 하퇴 길이). 학습자가 무릎 모멘트 팔을 고르면 정답 수선(0.12 m)이 강조된다.
- 속성:
  - P1 [I] 선분 클릭 선택 — 필수
  - P2 [G] 정답 선분은 작용선과 직각 — 필수
  - P3 [X] 오답 선택 시 그 선분이 왜 아닌지 한 줄 — 선택
