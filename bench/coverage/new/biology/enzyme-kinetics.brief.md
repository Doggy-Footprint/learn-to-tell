# 생명과학 · 효소와 반응 속도
## 상황
- 작업: 효소 활성 분석(plate reader 흡광도 시계열)에서 초기 속도를 뽑아 Km·Vmax를 맞추는 파이프라인 단계를 구현한다. 학습 자료를 만들어 달라.
- 배경: 고등학교 생물에서 "효소는 단백질 촉매, 자물쇠-열쇠" 정도만 기억한다. 미분·회귀는 익숙하다. 실험 데이터는 96-well 흡광도(A405, 30초 간격, 10분)이다.
## 진단 결과(고정)
- 사다리(낮은 단부터): 효소는 활성화 에너지를 낮춘다(알고 있음) → 기질 결합과 활성 부위·포화(애매함) → 초기 속도의 의미(아예 모름) → Michaelis-Menten의 Km·Vmax 해석(아예 모름) → 저해제가 곡선을 바꾸는 방식(아예 모름)
- 학습 수준: 2단(포화)~5단(저해). 1단은 hook에서 짧게 확인만 한다.
- 오개념: "기질을 두 배 넣으면 반응 속도도 언제나 두 배가 된다"라고 답했다.

## 그림
### F1 에너지 지형(반응 좌표)
- 보여 주는 것: 반응 좌표에 따른 자유 에너지. 비촉매 경로와 효소 경로를 겹쳐 그리고, 출발·도착 에너지(ΔG)는 같으며 활성화 에너지만 다름을 보인다.
- 속성:
  - P1 [G] 두 경로의 시작점과 끝점 높이가 같다 — 필수, 효소가 평형(ΔG)을 바꾸지 않는다는 결론이 여기서 나온다.
  - P2 [Q] 세로축 kJ/mol, 비촉매 Ea≈75, 촉매 Ea≈30(예시값임을 표기), 선형 — 선택, 크기 감각용.
  - P3 [E] Ea 차이를 양방향 화살표로 강조 — 필수, 핵심 관계.
  - P4 [X] "예시 값, 특정 효소 아님" 표기 — 필수, 사실성 원칙.
### F2 기질 농도별 효소 점유(분자 장면)
- 보여 주는 것: 고정된 효소 20개가 있는 상자에 기질 입자가 확산하며 결합·해리·생성물 방출. 슬라이더로 [S]를 바꾸면 점유된 효소 비율과 단위 시간 생성물 수가 함께 변한다.
- 속성:
  - P1 [T] 연속 루프 애니메이션, 결합-촉매-방출이 확률적으로 일어난다 — 필수, 포화가 "빈 효소가 없어서"임을 보인다.
  - P2 [I] [S] 슬라이더 0.1~100×Km, log 눈금 — 필수.
  - P3 [Q] 점유율 = [S]/(Km+[S]) 로 확률을 설정, 화면 카운터에 점유율과 생성 속도 표시 — 필수, 그림이 MM 식과 일치해야 한다.
  - P4 [X] "분자 크기·간격·속도는 축척 아님" — 필수.
  - P5 [E] 빈 효소는 윤곽만, 결합한 효소는 채움 — 필수.
### F3 예측-공개 그래프(v vs [S])
- 보여 주는 것: 학습자가 [S]를 1→10 mM로 올렸을 때의 속도를 직접 점으로 찍고, 공개 시 실제 쌍곡선(Km=2 mM, Vmax=100 µM/min)이 그려진다.
- 속성:
  - P1 [I] 학습자가 점을 드래그해 예측을 고정 — 필수.
  - P2 [Q] 축: [S] 0~20 mM 선형, v 0~120 µM/min — 필수.
  - P3 [G] 비례 직선(오개념)을 점선으로 겹쳐 쌍곡선과 차이 표시 — 필수, 오개념 교정.
  - P4 [X] 1 mM→v=33, 10 mM→v=83 수치 라벨 — 선택.
### F4 촉매 순환 단계도
- 보여 주는 것: E + S → ES → EP → E + P 4단계. 활성 부위 모양, 유도적합(결합 시 모양 변화), 생성물 방출 후 효소가 원상태로 돌아옴.
- 속성:
  - P1 [T] 단계별 진행(다음 버튼) — 필수.
  - P2 [G] 효소는 마지막 단계에서 처음과 같은 모양 — 필수, 효소가 소모되지 않는다.
  - P3 [G] 결합 시 활성 부위가 기질을 감싸도록 변형(유도적합) — 선택, 자물쇠-열쇠 수정.
  - P4 [Q] kcat 예시 표기: 탄산탈수효소 ~10^6 /s, 키모트립신 ~10^2 /s(교과서 값) — 선택.
  - P5 [X] "단순화된 2차원 모식도" — 필수.
### F5 진행 곡선과 초기 속도
- 보여 주는 것: [P] vs 시간(0~10분, 30초 간격 점). 처음엔 직선, 기질 소모로 휘어짐. 학습자가 맞춤 구간 핸들을 옮기면 기울기와 그 값이 갱신된다.
- 속성:
  - P1 [Q] 시뮬레이션: MM 적분형, [S]0=1 mM, Km=2 mM, Vmax=100 µM/min, 흡광도 노이즈 σ=0.005 — 필수.
  - P2 [I] 구간 시작·끝 핸들 — 필수.
  - P3 [E] 기질 소모 10% 이내 구간을 배경 띠로 표시, 그 밖이면 기울기가 과소 추정됨을 수치로 보임 — 필수, 파이프라인 결정의 핵심.
  - P4 [S] 오른쪽 inset에 남은 [S] 비율 막대 — 선택.
  - P5 [X] 기울기 값과 참값 차이(%) — 필수.
### F6 Km·Vmax 맞춤 탐색기
- 보여 주는 것: 8개 [S]에서의 초기 속도 데이터 점(오차 막대)과 학습자가 핸들로 조정하는 MM 곡선. Vmax는 수평 점근선, Km은 v=Vmax/2 지점.
- 속성:
  - P1 [I] Vmax(점근선 높이), Km(반속도 지점) 핸들 직접 드래그 — 필수.
  - P2 [Q] [S] = 0.25, 0.5, 1, 2, 4, 8, 16, 32 mM, 참값 Km=2, Vmax=100, 5% 노이즈; 잔차제곱합 표시 — 필수.
  - P3 [I] x축 선형/log 전환 — 선택, log에서 Km 근처가 S자 중앙이 됨.
  - P4 [E] Vmax/2 수평선과 Km 수직선 교점 강조 — 필수.
  - P5 [T] 목표: SSR이 최적의 110% 이내 도달 시 성공 표시 — 선택.
### F7 저해제 비교(같은 축 두 패널)
- 보여 주는 것: 저해제 없음 곡선을 기준으로, 왼쪽 경쟁적 저해(Km 증가, Vmax 동일), 오른쪽 비경쟁적 저해(Vmax 감소, Km 동일). 위에 분자 모식도(활성 부위 경쟁 / 다른 자리 결합).
- 속성:
  - P1 [S] 좌우 small multiples, 같은 축 범위 — 필수, 비교가 성립하려면.
  - P2 [Q] [I]=Ki일 때: 경쟁적 Km_app=2Km, 비경쟁적 Vmax_app=Vmax/2 — 필수.
  - P3 [I] [I]/Ki 슬라이더 0~5 두 패널 동시 적용 — 선택.
  - P4 [E] 경쟁적 패널에서 높은 [S]에서 곡선이 기준으로 수렴함을 강조 — 필수.
### F8 퀴즈용 데이터 판독 그림
- 보여 주는 것: 미지 시료의 v–[S] 데이터 두 세트(저해제 ±). 학습자가 어떤 저해 유형인지와 Km을 고른다.
- 속성:
  - P1 [Q] 경쟁적 저해 데이터, Km 2→6 mM, Vmax 동일 — 필수.
  - P2 [X] 축 라벨과 단위만, 답 힌트 없음 — 필수.
### F9 정리 지도
- 보여 주는 것: 흡광도 → [P] → 초기 기울기 → v–[S] → Km·Vmax → 저해 판정의 파이프라인 흐름에 각 단계 그림 썸네일을 매단 도식.
- 속성:
  - P1 [S] 왼쪽→오른쪽 단계 흐름 — 필수.
  - P2 [X] 각 단계의 주의점 한 줄(예: "소모 10% 이내") — 필수.
