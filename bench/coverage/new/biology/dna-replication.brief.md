# 생명과학 · DNA 복제
## 상황
- 작업: 시퀀싱 리드의 방향성(5'→3')·가닥 정보를 다루는 정렬 후처리 단계를 맡는다. 학습 자료를 만들어 달라.
- 배경: "DNA는 이중나선, A-T·G-C" 정도만 기억한다. 문자열 역상보(reverse complement)는 코드로 써 봤지만 왜 그런지는 모른다.
## 진단 결과(고정)
- 사다리(낮은 단부터): 염기쌍 상보성(알고 있음) → 가닥의 방향성 5'/3'과 역평행(애매함) → 반보존적 복제(애매함) → 중합효소는 3' 끝에만 붙인다(아예 모름) → 복제 분기점의 선도·지연 가닥과 오카자키 절편(아예 모름)
- 학습 수준: 2단(역평행)~5단(복제 분기점).
- 오개념: "두 가닥 모두 분기점이 움직이는 방향으로 똑같이 연속해서 복제된다"라고 답했다.

## 그림
### F1 역평행 사다리와 문자열
- 보여 주는 것: 8 bp 이중가닥을 펼친 사다리로 그리고, 각 가닥 끝에 5'/3'을 표기. 아래에 두 가닥을 각자 5'→3'로 읽은 문자열이 서로의 역상보임을 연결선으로 보인다.
- 속성:
  - P1 [G] 두 가닥 화살표 방향이 반대 — 필수, 역상보의 원인.
  - P2 [I] 위 가닥 염기를 클릭해 바꾸면 짝 염기와 아래 문자열이 함께 바뀜 — 선택.
  - P3 [E] 같은 위치의 염기쌍과 문자열 인덱스(i ↔ n−1−i)를 같은 색으로 연결 — 필수.
  - P4 [X] "나선 꼬임을 펼친 모식도" — 필수.
### F2 뉴클레오타이드 골격 구조
- 보여 주는 것: 디옥시리보스 고리의 탄소 번호 1'~5', 5' 탄소의 인산, 3' 탄소의 OH. 두 뉴클레오타이드가 3'-OH와 다음 5'-인산 사이 포스포다이에스터 결합으로 이어지는 모습.
- 속성:
  - P1 [G] 5' 인산과 3' OH의 위치가 고리 반대편 — 필수, 방향성의 실체.
  - P2 [E] 3'-OH를 강조 색 — 필수, 다음 장면 연결.
  - P3 [X] 탄소 번호 라벨 — 필수.
  - P4 [Q] 결합 각·길이는 정확하지 않다는 표기 — 필수.
### F3 분기점 예측 캔버스
- 보여 주는 것: 벌어진 Y자 분기점(진행 방향 오른쪽 화살표)과 두 주형 가닥의 방향. 학습자가 각 주형 위에 새 가닥이 자라는 방향 화살표를 그려 넣고, 공개 시 정답(위: 연속, 아래: 반대 방향 조각들)이 겹쳐진다.
- 속성:
  - P1 [I] 각 주형에 화살표 방향 선택 및 '연속/조각' 선택 — 필수.
  - P2 [G] 공개 시 학습자 답과 정답 겹침 — 필수, 오개념 교정.
  - P3 [X] 주형 끝 5'/3' 표기 — 필수.
### F4 중합효소 한 걸음
- 보여 주는 것: 주형 위 프라이머 3' 끝에 dNTP가 들어와 짝을 이루고, 피로인산(PPi)이 떨어지며 결합이 생기는 단계. 이어서 5' 끝 쪽에는 붙일 수 없음을 X 표시로 보인다.
- 속성:
  - P1 [T] 4단계 진행: dNTP 접근 → 염기쌍 확인 → 결합 형성·PPi 방출 → 한 칸 전진 — 필수.
  - P2 [G] 새 가닥은 주형과 역평행으로 3' 방향으로만 자란다 — 필수, 지연 가닥 문제의 근거.
  - P3 [E] 프라이머가 없으면 시작할 수 없음 — 선택(RNA 프라이머 장면 연결).
  - P4 [Q] 오류율 표기: 교정 포함 ~10^-7/염기, 불일치 복구 후 ~10^-9~10^-10 — 선택.
### F5 복제 분기점 애니메이션
- 보여 주는 것: 헬리케이스가 이중가닥을 풀며 오른쪽으로 전진. 선도 가닥은 중합효소가 따라가며 연속 합성. 지연 가닥은 프라이메이스가 RNA 프라이머를 놓고 중합효소가 분기점 반대 방향으로 오카자키 절편 합성, 이후 프라이머 제거·리게이스 연결. SSB, 토포아이소머레이스 위치 표시.
- 속성:
  - P1 [T] 단계 모드와 연속 루프 모드 전환 — 필수.
  - P2 [G] 지연 가닥 절편의 합성 방향이 분기점 진행 방향과 반대 — 필수, 핵심 관계.
  - P3 [E] 선도/지연 가닥을 두 색, RNA 프라이머 제3색 — 필수.
  - P4 [Q] 분기점 속도 대장균 ~1000 nt/s, 사람 ~50 nt/s; 오카자키 절편 대장균 1000~2000 nt, 진핵 100~200 nt(교과서 값) — 필수.
  - P5 [X] "효소 크기·DNA 길이 비례 아님, 지연 가닥 고리(트롬본) 생략" — 필수.
  - P6 [S] 상단 inset: 염색체 전체에서 이 분기점의 위치(복제 기점에서 양방향 거품) — 선택.
### F6 분기점 탐색기
- 보여 주는 것: 분기점 속도와 프라이머 개시 간격 슬라이더. 지정 시간(예 1초) 동안 생긴 선도 가닥 길이, 절편 수, 남은 미연결 틈 수를 실시간으로 그린다.
- 속성:
  - P1 [I] 속도 50~1000 nt/s, 개시 간격 100~2000 nt — 필수.
  - P2 [Q] 절편 수 = 진행 길이 / 개시 간격, 선형 축 nt — 필수.
  - P3 [T] 목표: 대장균 조건 맞추기(1초에 절편 ~1개 생성) — 선택.
  - P4 [E] 지연 가닥의 틈(nick)을 점으로 강조 — 선택.
### F7 반보존적 vs 보존적 비교
- 보여 주는 것: 15N(무거운) 가닥은 진한 색, 14N은 연한 색. 0·1·2세대 DNA 분자를 두 모델로 나란히 그리고, 아래에 각 모델이 예측하는 원심분리 띠(무거움/중간/가벼움) 위치를 표시. 실제 결과(Meselson–Stahl, 1958): 1세대 중간 띠 하나, 2세대 중간:가벼움 1:1.
- 속성:
  - P1 [S] 좌우 두 모델, 같은 세대 행 정렬 — 필수.
  - P2 [Q] 띠 비율 세대 n에서 중간 2/2^n, 가벼움 1−2/2^n — 필수.
  - P3 [E] 실제 데이터와 일치하는 모델 패널 강조 — 필수.
  - P4 [X] 띠 위치는 밀도 순서만 의미, 거리 축척 아님 — 필수.
### F8 퀴즈 그림
- 보여 주는 것: 양방향 복제 거품 하나와 주형 방향만 주고, 네 군데 중 어느 곳이 지연 가닥인지 고르게 한다.
- 속성:
  - P1 [G] 거품 양쪽 분기점에서 선도/지연이 주형 가닥 기준으로 뒤바뀐다 — 필수, 이해 검증의 핵심.
  - P2 [I] 네 영역 클릭 선택 — 필수.
### F9 정리 그림
- 보여 주는 것: 역평행 → 3'에만 붙임 → 선도 연속/지연 조각 → 역상보 문자열의 인과 사슬 도식.
- 속성:
  - P1 [S] 왼→오 사슬, 앞 그림 축소판 — 필수.
  - P2 [X] 각 고리에 한 문장 — 필수.
