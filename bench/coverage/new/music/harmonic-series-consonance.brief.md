# 음악 · 배음렬과 협화·불협화
## 상황
- 작업: 작곡 보조 앱의 "어울리는 음 추천" 기능이 왜 어떤 음정을 더 협화적으로 점수 매기는지 기획 문서에 근거를 적는다. 학습 자료를 만들어 달라.
- 배경: 기타를 조금 쳐 봤고 옥타브·5도가 "잘 어울린다"는 감각은 있다. 주파수, 배음, 맥놀이, 평균율은 체계적으로 배운 적 없다.
## 진단 결과(고정)
- 사다리(낮은 단부터): 음높이 = 진동수(알고 있음) → 한 음은 여러 배음의 합(애매함) → 음정 = 진동수 비(애매함) → 배음끼리 가까우면 맥놀이·거칠기(아예 모름) → 평균율은 단순 정수비에서 조금 어긋난다(아예 모름)
- 학습 수준: 2단(배음)부터 5단(평균율 오차)까지
- 오개념: "음 두 개가 가까울수록 더 잘 어울린다(반음이 장6도보다 협화적이다)"라고 답했다.

## 그림
### F1 현의 정상파 모드
- 보여 주는 것: 양끝이 고정된 현 하나에 1~6차 모드(마디 0,1,2,…,5개)가 세로로 쌓여 각각 진동하고, 맨 아래에 그 합이 실제 현의 모양으로 진동한다.
- 속성:
  - P1 [G] n차 모드는 현 길이를 정확히 n등분하는 마디를 가진다 — 필수, 배음이 정수배라는 결론의 근거
  - P2 [T] n차 모드는 1차보다 정확히 n배 빠르게 진동(루프 애니메이션, 1차 주기 2초) — 필수, 진동수 = n×f₀를 눈으로 확인
  - P3 [Q] 진폭은 대략 1/n로 감소(뜯은 현 근사), 진폭 확대 표기 — 선택, 상위 배음이 약하다는 사실
  - P4 [S] 모드별 small multiples + 하단 합성 파형 — 필수
  - P5 [X] 각 모드 옆에 "n×110 Hz"(A2 기준) — 필수
  - P6 [E] 진폭 과장 표시 "진폭 ×20 과장" — 필수, 축척 왜곡 고지

### F2 배음렬 사다리(오선+진동수 축)
- 보여 주는 것: C2(65.4 Hz)의 1~16배음을 세로 로그 진동수 축 위 가로선으로, 옆에 가장 가까운 오선 음표를 함께 표기.
- 속성:
  - P1 [Q] 세로축 로그 스케일 65~1100 Hz, 옥타브마다 같은 간격 — 필수, 배음이 위로 갈수록 촘촘해짐을 보이기 위함
  - P2 [G] 2·4·8·16배음이 같은 음이름(C)으로 정렬 — 필수
  - P3 [X] 7·11·13배음 옆 "평균율보다 −31/−49/+41 cent" — 필수, 오선 표기가 근사임을 고지
  - P4 [E] 1~6배음을 진하게, 그 위는 흐리게 — 선택
  - P5 [I] 배음 선 탭 시 진동수·음이름 표시(소리 재생 가능 시 해당 배음 재생) — 선택

### F3 음정 = 진동수 비
- 보여 주는 것: 두 음의 파형을 같은 시간축에 겹쳐, 옥타브(2:1), 5도(3:2), 장3도(5:4), 단2도(16:15)에서 두 파형이 다시 같이 시작하는 주기를 표시.
- 속성:
  - P1 [Q] 시간축 동일 스케일, 기준음 220 Hz, 창 길이 20 ms — 필수
  - P2 [G] 공통 주기마다 세로 점선(2:1은 1주기, 3:2는 2주기, 16:15는 15주기) — 필수, 단순비 = 짧은 반복이라는 결론
  - P3 [S] 4개 음정 small multiples, 같은 시간 스케일 — 필수
  - P4 [X] 각 패널 "비 p:q, 반복 = 기준음 q주기" — 필수

### F4 두 음의 배음 겹치기
- 보여 주는 것: 가로 로그 진동수 축 위에 음 A(위쪽 빨강 막대)와 음 B(아래쪽 파랑 막대)의 1~10배음을 표시하고, 두 배음이 일치하면 하나로 합쳐 표시, 25~40 Hz 안쪽으로 가까우면 붉은 지그재그로 "부딪힘" 표시.
- 속성:
  - P1 [Q] 로그 진동수 축 100~3000 Hz, 막대 높이 = 진폭 1/n — 필수
  - P2 [G] 일치(같은 위치) vs 근접(임계대역 안) vs 멀리(무관) 세 관계 구분 — 필수, 협화의 원인
  - P3 [E] 부딪히는 쌍을 가장 먼저 보이게 강조 — 필수
  - P4 [I] predict: 학습자가 "C–G"와 "C–C#" 중 부딪힘이 많은 쪽을 고른 뒤 공개 — 필수
  - P5 [X] 임계대역 근사(약 중심주파수의 15~20%)라는 단순화 고지 — 필수

### F5 맥놀이
- 보여 주는 것: 440 Hz와 444 Hz 사인파와 그 합. 합 파형의 포락선이 초당 4번 커졌다 작아진다.
- 속성:
  - P1 [Q] 맥놀이 진동수 = |f1−f2| — 필수
  - P2 [T] 포락선이 실제 속도로 숨쉬는 루프(시간축은 1초 창) — 필수
  - P3 [I] f2 슬라이더 440~480 Hz, 차가 커질수록 맥놀이→거칠기→두 음 분리로 바뀜 표기 — 필수
  - P4 [X] "차 <~15 Hz 출렁임, ~20–40 Hz 거칠음, 더 크면 두 음" 구간 라벨 — 선택
  - 소리: 재생 가능하면 가장 효과가 큰 그림

### F6 거칠기(불협화) 곡선
- 보여 주는 것: 가로축 음정 0~1200 cent, 세로축 Plomp–Levelt/Sethares 모델로 계산한 6배음 복합음의 감각적 불협화도. 단순 정수비 위치(1:1, 6:5, 5:4, 4:3, 3:2, 5:3, 2:1)에 골짜기.
- 속성:
  - P1 [Q] Sethares(1993) 모델, 기준 261.6 Hz, 배음 진폭 0.88ⁿ, 세로축 상대값 0~1 — 필수
  - P2 [G] 골짜기 위치가 정수비 cent(316, 386, 498, 702, 884, 1200)와 일치 — 필수
  - P3 [E] 100 cent 부근 최고점과 702 cent 골짜기 대비 — 필수, 오개념 교정
  - P4 [I] 핸들로 음정 이동 → F4가 연동되어 부딪힘 개수 갱신; 목표 "가장 낮은 골짜기 3개 찾기" — 필수
  - P5 [I] 배음 수 토글(1개=사인파일 때 골짜기 사라짐) — 선택, 협화가 배음 때문임을 증명
  - P6 [X] "모델 계산값, 문화적 선호는 포함 안 함" — 필수

### F7 순정 vs 평균율
- 보여 주는 것: 12음 원 위에 평균율 위치(100 cent 간격)와 순정비 위치를 같이 찍어 오차를 화살표로.
- 속성:
  - P1 [Q] 오차 값: 5도 −1.96, 장3도 +13.7, 단3도 −15.6 cent — 필수
  - P2 [E] 오차를 실제보다 확대(×5)해 표시하고 그 사실 표기 — 필수
  - P3 [S] compare: 같은 F4를 순정 5도/평균율 5도로 나란히, 평균율에서 3배음·2배음 쌍이 약 0.9 Hz로 맥놀이 — 필수
  - P4 [X] "피아노·DAW 기본값은 평균율" — 선택

### F8 협화도 순위 퀴즈 카드
- 보여 주는 것: 음정 카드 5장(단2도, 장3도, 완전5도, 증4도, 옥타브)을 F6 곡선 위 위치에 끌어다 놓기.
- 속성:
  - P1 [I] 드래그로 순서 제출 후 정답 위치 공개 — 필수
  - P2 [Q] 공개 시 F6과 같은 세로 스케일 — 필수
