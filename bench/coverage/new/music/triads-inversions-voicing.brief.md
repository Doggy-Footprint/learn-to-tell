# 음악 · 3화음의 구성·전위·보이싱(건반·오선·지판)
## 상황
- 작업: 작곡 보조 앱의 "코드 입력 → 건반/기타 운지 자동 표시" 기능 화면을 기획한다. 학습 자료를 만들어 달라.
- 배경: 기타 오픈 코드 몇 개를 외워 쳐 봤다. 코드 이름과 실제 구성음, 전위, 같은 코드의 다른 운지가 어떤 관계인지는 모른다.
## 진단 결과(고정)
- 사다리(낮은 단부터): 건반의 음이름(알고 있음) → 반음 단위 음정 세기(애매함) → 3화음 = 3도 쌓기, 장/단/감/증(애매함) → 전위와 베이스음(아예 모름) → 같은 화음의 보이싱이 건반·지판에서 여러 모양(아예 모름)
- 학습 수준: 2단부터 5단까지
- 오개념: "C 코드는 기타에서 그 모양 하나뿐이고, 맨 아래 음이 뭐든 똑같은 C다"라고 답했다.
## 장면 목록
1. 같은 'C'인데 소리가 다른 세 운지 / hook
2. 반음 세기와 3도 / define
3. 3도를 쌓아 장·단·감·증 만들기 / steps
4. 전위를 바꾸면 무엇이 바뀌나 / predict
5. 지판 위에서 C 장3화음 모두 찾기 / explore
6. 근음 위치 vs 1전위 / compare
7. 코드 이름 맞히기 / quiz
8. 요약 / summary

## 그림
### F1 건반–오선–지판 3중 연동 뷰
- 보여 주는 것: 위에 2옥타브 피아노 건반(C3–B4), 가운데 대보표, 아래 기타 지판(표준 조율 EADGBE, 0–15프렛). 한 화음의 구성음이 세 곳에 같은 색으로 동시에 표시된다.
- 속성:
  - P1 [G] 건반의 흰/검은 건반 배치가 실제(2–3 묶음), 지판 프렛 간격은 실제처럼 브리지 쪽으로 2^(−1/12)씩 좁아짐 — 필수, 앱 화면 기획의 실물 대응
  - P2 [G] 같은 음높이는 세 뷰에서 같은 색, 다른 옥타브의 같은 음이름은 같은 색상 다른 명도 — 필수, "음이름 같음 ≠ 음높이 같음" 구분
  - P3 [X] 기타는 실제 음보다 한 옥타브 높게 기보한다는 표기 — 필수, 사실성
  - P4 [I] 어느 뷰에서 음을 탭해도 나머지 두 뷰에 반영 — 필수
  - P5 [S] 세 뷰 세로 정렬, 건반과 지판의 같은 음을 잇는 옅은 선(선택 시) — 선택

### F2 반음 자(semitone ruler)
- 보여 주는 것: 건반 위로 두 음 사이 반음 개수를 원호 점프로 세고, 그 결과 음정 이름(단3도=3, 장3도=4, 완전5도=7)을 표시.
- 속성:
  - P1 [Q] 반음 = 인접 건반(검은 건반 포함), E–F, B–C도 반음 — 필수, 흔한 오해 교정
  - P2 [T] 단계별 점프 애니메이션(1칸씩) — 필수
  - P3 [X] 점프 수 누적 카운터 — 필수

### F3 3도 쌓기 → 4종 3화음
- 보여 주는 것: 근음 C 위에 3도 두 개를 쌓는 과정. 장(4+3), 단(3+4), 감(3+3), 증(4+4)을 건반과 오선(눈사람 모양: 줄-줄-줄 또는 칸-칸-칸)으로.
- 속성:
  - P1 [G] 오선에서 3화음은 같은 종류의 자리(모두 줄 또는 모두 칸)에 겹침 — 필수, 악보에서 3화음을 알아보는 기준
  - P2 [Q] 각 3도의 반음 수 라벨, 근음–5음 합계(7/7/6/8) — 필수
  - P3 [S] 4종 small multiples, 같은 근음 — 필수
  - P4 [T] steps: 근음 → +3도 → +3도 순서로 쌓임 — 필수
  - P5 [E] 장/단 차이(가운데 음 반음 하나) 강조 — 필수

### F4 전위 사다리
- 보여 주는 것: C 장3화음의 근음 위치(C–E–G), 1전위(E–G–C), 2전위(G–C–E)를 오선과 건반에 나란히. 가장 낮은 음(베이스)을 강조.
- 속성:
  - P1 [G] 구성음 집합은 동일, 맨 아래 음만 바뀜 — 필수, 오개념 교정의 핵심
  - P2 [X] 코드 표기 C, C/E, C/G — 필수, 앱 UI와 직결
  - P3 [T] 맨 아래 음이 한 옥타브 위로 올라가는 단계 애니메이션 — 필수
  - P4 [I] predict: "1전위의 맨 아래 음은?" 답한 뒤 공개 — 필수
  - P5 [Q] 각 형태 안 음정(반음): 4+3 / 3+5 / 5+4 — 선택

### F5 지판 위 C 장3화음 지도
- 보여 주는 것: 0–15프렛 지판에 C(근음), E(3음), G(5음)의 모든 위치를 다른 모양(●, ▲, ■)으로 찍고, CAGED 다섯 운지 모양을 반투명 영역으로 겹친다.
- 속성:
  - P1 [G] 모든 위치가 표준 조율 기준으로 정확(예: 5번 줄 3프렛 = C3) — 필수
  - P2 [I] 학습자가 3·4·5줄 범위 등 손 위치 창(4프렛 폭)을 끌어 그 안에서 C 운지를 완성; 목표 "서로 다른 운지 3개 찾기" — 필수
  - P3 [E] 각 운지에서 가장 낮은 줄의 음(베이스)을 강조, 전위 이름 자동 표시 — 필수
  - P4 [X] 근음/3음/5음 범례 — 필수
  - P5 [G] 12프렛 이후 패턴 반복 표시 — 선택

### F6 근음 위치 vs 1전위 비교
- 보여 주는 것: 같은 진행 C–F–G–C를 (a) 모두 근음 위치로, (b) 가까운 전위로 연결해 두 대보표에 나란히. 성부 이동 거리를 화살표 반음 수로.
- 속성:
  - P1 [Q] 각 성부 이동 반음 합계: (a) 대략 20+ vs (b) 한 자리 수 — 필수, 전위가 매끄러운 연결의 수단임을 보임
  - P2 [S] compare, 같은 오선 스케일 좌우 — 필수
  - P3 [E] 공통음(유지되는 음)을 이음줄로 강조 — 필수
  - P4 [X] 소리 재생 가능하면 두 버전 비교 재생 버튼 — 선택

### F7 음 공간 원(크로마 원)
- 보여 주는 것: 12음 원 위에 3화음을 삼각형으로. 장3화음은 모두 같은 삼각형 모양, 회전만 다름; 단3화음은 거울상.
- 속성:
  - P1 [G] 꼭짓점 간 원호 = 반음 수(4,3,5) — 필수, 장/단의 구조적 동일성
  - P2 [I] 삼각형 회전 → 근음 바뀜, 반전 → 장↔단 — 선택
  - P3 [X] "옥타브 차이는 원에서 사라짐(음높이 아님 음이름)" 표기 — 필수, 단순화 고지

### F8 코드 이름 퀴즈
- 보여 주는 것: 건반 또는 지판에 무작위 3음 보이싱을 표시, 학습자가 코드 이름과 슬래시 베이스(예: Am/C) 입력.
- 속성:
  - P1 [I] 답 제출 후 F1처럼 근음/3음/5음 색 공개 — 필수
  - P2 [G] 문제에 겹친 음(배가)·넓은 간격 보이싱 포함 — 선택
