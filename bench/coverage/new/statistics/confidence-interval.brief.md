# 통계 · 신뢰구간과 표본분포
## 상황
- 작업: 캠페인 성과 보고서에 적힌 "전환율 4.2% (95% CI 3.6%–4.8%)"를 바르게 해석해 상사에게 설명해야 한다. 학습 자료를 만들어 달라.
- 배경: 이커머스 마케터. 대학 통계 수업은 10년 전에 들었고, 평균·비율 계산은 엑셀로 한다. 표본 크기와 오차의 관계, 신뢰구간의 '95%'가 무엇에 대한 확률인지는 설명하지 못한다.
## 진단 결과(고정)
- 사다리(낮은 단부터): 표본 비율은 모집단 비율의 추정치다(알고 있음) → 표본마다 추정치가 흔들린다(표본분포)(애매함) → 표준오차는 √n에 반비례한다(아예 모름) → 95%는 구간을 만드는 절차의 적중률이다(아예 모름)
- 학습 수준: 표본분포, 표준오차, 신뢰구간의 빈도 해석
- 오개념: "95% 신뢰구간은 진짜 전환율이 이 구간 안에 있을 확률이 95%라는 뜻"이라고 답했다.

## 그림
### F1 방문자 표본 추출 장면
- 보여 주는 것: 진짜 전환율 4%인 방문자 10,000명(점 격자, 구매자 400명 채색) 중 무작위 500명을 집어 표본 전환율을 계산하는 과정
- 속성:
  - P1 [Q] 모집단 100×100 점, 구매자 정확히 400개 무작위 위치 — 필수, 비율이 실제 4%여야 그림이 사실과 대응
  - P2 [T] 클릭마다 500개 점이 빛나며 오른쪽 표본 상자로 이동, 표본 전환율(예: 3.4%, 4.6%) 표시 — 필수, '표본마다 다름'을 눈으로 확인
  - P3 [E] 진짜 전환율 4%는 회색 작은 글씨, 표본값은 굵게 — 필수, 실무에서는 진짜 값을 모른다는 사실 반영
  - P4 [X] "실제로는 모집단 전체를 볼 수 없음" 주석 — 필수, 신의 시점이라는 단순화 표시
### F2 표본 전환율 점도표(누적)
- 보여 주는 것: F1의 반복 추출 결과가 가로축(2%–6%)에 점으로 쌓여 표본분포 모양이 생기는 과정
- 속성:
  - P1 [Q] x축 2.0%–6.0%, 0.2%p 구간, 점 1개=추출 1회, 이항분포 n=500,p=0.04 시뮬레이션 — 필수, 실제 분포와 일치
  - P2 [T] 자동 재생 1회/0.2초, 최대 1,000회 — 필수, 쌓이며 종 모양이 드러남
  - P3 [G] 4% 위치 수직 기준선 — 필수, 분포 중심이 진짜 값임을 보여 줌
  - P4 [E] 마지막으로 추가된 점 강조 — 선택, F1과 연결
### F3 표본 크기 슬라이더 표본분포
- 보여 주는 것: n을 바꾸면 표본분포 폭이 1/√n으로 줄어드는 모습
- 속성:
  - P1 [I] n 슬라이더 100–10,000 (로그 눈금) — 필수, 학습자가 직접 관계 탐색
  - P2 [Q] 이론 정규곡선 SE=√(0.04·0.96/n); n=500에서 SE≈0.88%p, n=2000에서 0.44%p — 필수, 정확한 수치
  - P3 [G] x축 고정(2%–6%) — 필수, 축이 움직이면 폭 변화가 감춰짐
  - P4 [I] 목표: "±1%p 안에 95%가 들어오게" 하는 n 찾기(≈1,475) — 필수, explore 목표
  - P5 [X] 현재 SE 수치 라벨 — 필수
### F4 표준오차 공식 분해도
- 보여 주는 것: SE=√(p(1−p)/n)의 각 항을 F3 곡선 폭과 연결
- 속성:
  - P1 [S] 왼쪽 공식, 오른쪽 곡선; 항에 마우스 올리면 대응 부분 강조 — 필수
  - P2 [Q] n을 4배 → SE 1/2배 를 막대 두 개로 표시 — 필수, √ 관계가 핵심
  - P3 [E] √ 기호 가장 강조 — 필수, 직관(비례)과 다른 지점
### F5 신뢰구간 100개 줄
- 보여 주는 것: 표본 100번 각각의 95% CI를 가로 막대로 세로로 쌓고 4% 선을 지나지 않는 막대 표시
- 속성:
  - P1 [Q] 각 구간 p̂±1.96·SE, n=500; y축 추출 번호 1–100 — 필수
  - P2 [G] 진짜 값 4% 수직선 — 필수, 적중 판정 기준
  - P3 [E] 빗나간 구간(기댓값 약 5개) 빨강 — 필수, 핵심 관계
  - P4 [T] 단계 진행: 1개 → 10개 → 100개, 적중 수 카운터 — 필수
  - P5 [X] "고정된 것은 진짜 값, 움직이는 것은 구간" — 필수, 오개념 교정
### F6 n=500 대 n=5,000 구간 비교
- 보여 주는 것: 같은 F5를 두 조건으로 나란히, 구간 폭 약 √10≈3.2배 차이
- 속성:
  - P1 [S] 좌우 동일 x축(2%–6%) — 필수, 공정 비교
  - P2 [Q] 평균 폭 n=500: ±1.72%p, n=5,000: ±0.54%p — 필수
  - P3 [E] 두 조건 모두 적중률 약 95%로 같음을 강조 — 필수, 폭이 줄어도 신뢰수준은 같음
### F7 보고서 CI 읽기 도식
- 보여 주는 것: "4.2% (3.6–4.8%)"를 수직선 위 점과 막대로 옮기고 기준값(지난 캠페인 3.5%) 위치 비교
- 속성:
  - P1 [Q] 수직선 3%–5.5%, 점 4.2, 막대 3.6–4.8, 기준 3.5 — 필수
  - P2 [G] 기준값이 막대 밖에 있음 — 필수, p<0.05와의 연결
  - P3 [X] "이 하나의 구간은 맞았거나 틀렸다; 95%는 방법의 성공률" — 필수
