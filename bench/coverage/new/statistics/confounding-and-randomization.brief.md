# 통계 · 관찰 연구와 무작위 실험(교란)
## 상황
- 작업: "쿠폰 받은 고객의 재구매율이 14.5%p 높다"는 보고서가 쿠폰 효과를 보여 주는지 판단해야 한다. 학습 자료를 만들어 달라.
- 배경: 이커머스 마케터. CRM으로 VIP 고객에게 쿠폰을 보내 왔고, 보고서 p값이 작으면 효과가 확실하다고 여겨 왔다. 실험 설계 용어는 들어 본 적만 있다.
## 진단 결과(고정)
- 사다리(낮은 단부터): 두 집단 비교로 차이를 측정한다(알고 있음) → 상관은 인과가 아니다(애매함) → 교란변수가 처치와 결과 모두에 영향을 준다(아예 모름) → 무작위 배정이 교란 경로를 끊는다(아예 모름) → p값은 차이의 우연성만 말하고 원인은 말하지 않는다(애매함)
- 학습 수준: 교란, 인과 그래프, 무작위 배정, 관찰 연구의 한계
- 오개념: "p값이 0.001이면 쿠폰이 재구매를 늘렸다는 게 증명된 것"이라고 답했다.
## 장면 목록
1. 쿠폰 효과 14.5%p? / hook
2. 쿠폰을 안 보냈어도 차이가 났을까? / predict
3. 교란변수 / define
4. 누가 쿠폰을 받았나 / explain
5. 인과 그래프 그리기 / steps
6. 배정 방식 바꾸기 / explore
7. 관찰 연구 대 무작위 실험 / compare
8. 보고서 판정 / quiz
9. 정리: 인과 주장을 읽는 세 질문 / final summary
## 그림
### F1 고객 2,000명 배정 장면
- 보여 주는 것: 고객 아이콘 2,000개를 과거 구매 횟수로 색칠(VIP 400명 진하게), CRM 규칙 "구매 5회 이상에게 쿠폰"으로 쿠폰 집단이 채워지는 과정
- 속성:
  - P1 [Q] 고객 2,000명, VIP 비율 20%; 쿠폰 집단 500명 중 VIP 360명(72%), 비쿠폰 1,500명 중 VIP 40명(약 3%) — 필수, 수치가 이후 효과 계산과 맞물림
  - P2 [T] 규칙 적용 애니메이션: 아이콘이 두 상자로 이동 — 필수, 배정이 '선택'임을 보여 줌
  - P3 [E] VIP 색이 쿠폰 상자에 몰리는 것이 가장 먼저 보이게 — 필수, 핵심 관계
  - P4 [X] "아이콘 1개=고객 1명" — 선택
### F2 재구매율 막대와 분해
- 보여 주는 것: 쿠폰 27.0% 대 비쿠폰 12.5%(차이 14.5%p), 이를 VIP/일반으로 쪼개면 쿠폰 효과는 두 층 모두 +2%p
- 속성:
  - P1 [Q] 가정 데이터: VIP 재구매 30%(쿠폰 시 32%), 일반 12%(쿠폰 시 14%); 쿠폰 0.72·32+0.28·14=27.0%, 비쿠폰 (40·30+1460·12)/1500=12.5% — 필수, 전체 막대가 층별 값의 가중평균과 정확히 일치
  - P2 [T] 단계: 전체 막대 → 층별로 쪼개짐 — 필수
  - P3 [X] "가상 데이터" 표시 — 필수, 사실 표시 원칙
  - P4 [S] 같은 y축 0–40% — 필수
### F3 교란 인과 그래프(DAG)
- 보여 주는 것: 노드 '과거 구매(VIP)' → '쿠폰', '과거 구매' → '재구매', '쿠폰' → '재구매'
- 속성:
  - P1 [G] 화살표 방향 = 인과 방향, 화살표 두께 = 효과 크기(VIP→재구매 18%p, 쿠폰→재구매 2%p) — 필수
  - P2 [E] 뒷문 경로(쿠폰←VIP→재구매) 주황 강조 — 필수, 가짜 차이의 출처
  - P3 [T] steps: 노드 하나씩 추가, 경로마다 F2 막대 해당 부분 강조 — 필수
  - P4 [X] 그래프는 가정이며 데이터만으로 확정되지 않음 주석 — 필수
### F4 배정 방식 스위치
- 보여 주는 것: 배정 규칙(VIP 우선 ↔ 동전 던지기)과 VIP 우대 강도 슬라이더를 바꾸면 두 집단 VIP 구성과 관측 차이가 실시간 변함
- 속성:
  - P1 [I] 슬라이더 'VIP가 쿠폰 받을 확률' 25%–100%, 일반 고객 확률은 쿠폰 500명 고정되게 자동 조정 — 필수
  - P2 [Q] 관측 차이 = 2%p + 18%p×(VIP 비율 차) 공식으로 계산 — 필수
  - P3 [I] 목표: 관측 차이를 진짜 효과 2%p에 맞추기 — 필수, 무작위가 답임을 발견
  - P4 [G] F3 그래프가 함께 표시되어 VIP→쿠폰 화살표 두께가 슬라이더에 연동, 무작위일 때 사라짐 — 필수
### F5 무작위 배정 반복 분포
- 보여 주는 것: 무작위 배정 1,000회 반복 시 관측 차이 분포(중심 2%p)와 VIP 선택 배정의 단일값 14.5%p 위치
- 속성:
  - P1 [Q] x축 −4%p–16%p, 히스토그램 0.5%p 구간, SD≈1.9%p — 필수
  - P2 [E] 선택 배정 값이 분포 바깥 멀리 있음 강조 — 필수
  - P3 [X] "무작위면 차이는 효과+우연; 선택이면 효과+우연+교란" — 필수
### F6 관찰 연구 대 무작위 실험 비교
- 보여 주는 것: 같은 F1·F3 구성을 두 조건으로 나란히 — 왼쪽 CRM 선택, 오른쪽 무작위
- 속성:
  - P1 [S] 동일 배치·동일 축 — 필수
  - P2 [G] 오른쪽 그래프에서 VIP→쿠폰 화살표 제거 — 필수, 핵심 차이
  - P3 [Q] p값 둘 다 표시(왼쪽 p<0.001, 오른쪽 p≈0.3) — 필수, 작은 p값이 인과를 보장 안 함
### F7 연구 설계 흐름도
- 보여 주는 것: 고객 모집 → 배정(누가 정했나?) → 처치 → 측정, 각 단계에서 물어야 할 질문
- 속성:
  - P1 [S] 왼→오 4단계 상자 — 필수
  - P2 [E] '배정' 상자 가장 강조 — 필수, 진단의 핵심
  - P3 [X] 세 질문: 누가 배정했나 / 집단이 처치 전에 같았나 / 차이는 우연 범위 밖인가 — 필수
