# 경제학 · 경제의 순환과 국민소득(GDP) 측정
## 상황
- 작업: 투자 유치 자료의 '시장 규모' 슬라이드에서 국내 구독 서비스 지출이 GDP에서 차지하는 비중을 설명한다. 학습 자료를 만들어 달라.
- 배경: B2C 스타트업 PM. 구독 요금제 가격을 정하며 거시 지표를 인용하려 하지만 미시·거시 기초를 체계적으로 배운 적이 없다. GDP를 '기업 매출의 합'으로 이해하고 있다.
## 진단 결과(고정)
- 사다리(낮은 단부터): 가계와 기업, 생산물·생산요소 시장(애매함) → 실물 흐름과 화폐 흐름의 반대 방향(아예 모름) → 지출=소득=생산의 세 측면(아예 모름) → 부가가치와 중간재 이중계산(아예 모름) → 정부·해외 부문이 추가된 순환(아예 모름)
- 학습 수준: 가계와 기업 ~ 부가가치와 중간재 이중계산 (정부·해외 부문은 요약에서 미리보기)
- 오개념: "GDP는 나라 안 모든 기업 매출을 더한 것이다"라고 답했다.
## 장면 목록
1. 구독료 9,900원은 어디로 흘러가나 / hook
2. 모든 기업 매출을 더하면 GDP일까 / predict
3. 두 시장, 두 주체 / define
4. 돈과 물건은 반대로 돈다 / explain
5. 한 바퀴를 추적하기 / steps
6. 생산 단계별 부가가치 / explore
7. 매출 합 vs 부가가치 합 / compare
8. 정부와 해외가 끼어들면 / explain
9. 이 지출은 GDP에 들어가나 / quiz
10. 시장 규모 슬라이드 점검표 / final summary
## 그림
### F1 구독료 한 건의 행방
- 보여 주는 것: 사용자 1명이 낸 월 9,900원이 앱스토어 수수료(30%, 2,970원), 클라우드 비용(1,200원), 직원 급여(3,800원), 콘텐츠 라이선스(1,000원), 이윤(930원)으로 갈라지는 흐름도(Sankey 형태). 숫자는 가상 예시
- 속성:
  - P1 [Q] 흐름 폭이 금액에 비례, 합계 9,900원 보존 — 필수, 폭이 사실과 대응해야 함
  - P2 [T] 동전 입자가 왼쪽에서 오른쪽으로 흘러 갈라지는 루프 애니메이션 — 선택, 지출이 누군가의 소득이 됨을 동작으로
  - P3 [X] 각 갈래 끝에 '누군가의 소득' 라벨, 그림 귀퉁이에 '가상 비용 구조' 표기 — 필수
### F2 단순 순환도(2부문)
- 보여 주는 것: 왼쪽 가계, 오른쪽 기업, 위쪽 생산물 시장, 아래쪽 생산요소 시장 네 노드와 이를 잇는 두 개의 고리: 안쪽 고리는 실물(재화·서비스, 노동·자본), 바깥쪽 고리는 화폐(소비지출, 임금·이자·이윤)
- 속성:
  - P1 [G] 실물 고리와 화폐 고리는 같은 경로에서 반대 방향 화살표 — 필수, 핵심 관계
  - P2 [E] 화폐 흐름은 실선 굵게(주 색), 실물 흐름은 점선(보조 색) — 필수, 먼저 눈에 띌 대상 지정
  - P3 [I] 노드를 누르면 그 노드에서 나가고 들어오는 흐름만 하이라이트 — 선택
  - P4 [X] 각 화살표에 흐름 이름과 이 앱의 예(구독 서비스, 개발자 노동, 월급) — 필수
  - P5 [X] '저축·투자·정부·해외는 생략한 단순화 모형' 표기 — 필수, 단순화를 그림에 밝힘
### F3 한 바퀴 추적
- 보여 주는 것: F2 위에서 100만 원이 가계→생산물 시장→기업→생산요소 시장→가계로 한 바퀴 도는 과정을 4단계로 진행하고, 각 단계에서 '지출 100 / 생산 100 / 소득 100' 계기판이 채워짐
- 속성:
  - P1 [T] 단계 버튼 4개, 현재 구간의 화살표만 활성화 — 필수
  - P2 [Q] 세 계기판 값이 같은 눈금(0~100만 원)으로 같은 높이에 도달 — 필수, 세 측면 등가를 보여줌
  - P3 [S] 순환도 오른쪽에 세 계기판 인셋 — 필수
### F4 생산 단계 사슬(부가가치 탐색)
- 보여 주는 것: 밀 농가→제분소→제빵소→소비자로 이어지는 사슬. 각 단계 매출 블록이 이전 단계 구매분(중간재) + 자기 부가가치로 쌓인 막대(농가 100, 제분소 250, 제빵소 600, 단위 원)
- 속성:
  - P1 [G] 각 막대의 아래 부분(중간재)이 이전 단계 막대 전체와 같은 높이로 연결선 표시 — 필수, 이중계산의 출처가 기하로 보임
  - P2 [I] 각 단계 가격 슬라이더(제분소 150~400원, 제빵소 300~900원), 앞 단계보다 낮게는 못 내림 — 필수
  - P3 [Q] 부가가치 합 = 최종재 가격(600원)이 실시간 유지됨을 표시, 매출 합(950원)도 함께 — 필수
  - P4 [E] 부가가치 조각만 진한 색, 중간재 부분은 빗금 — 필수
  - P5 [I] 목표: '매출 합과 부가가치 합의 차이를 0으로 만드는 조건을 찾아라'(중간재 단계가 없을 때) — 선택
### F5 매출 합 vs 부가가치 합
- 보여 주는 것: F4 사례를 같은 축 위 두 쌓인 막대로: 매출 합 950원(100+250+600) vs 부가가치 합 600원(100+150+350)
- 속성:
  - P1 [S] 같은 축 나란히 — 필수
  - P2 [Q] 축 0~1,000원, 0 기점 — 필수
  - P3 [E] 차이 350원(=중간재 거래액)을 괄호로 표시 — 필수
  - P4 [X] '매출 합 ≠ GDP' 라벨 — 필수, 오개념 교정
### F6 앱 사업의 부가가치 사슬
- 보여 주는 것: F4 구조를 구독 앱에 적용: 클라우드 사업자(1,200원)→앱 회사→소비자(9,900원). 앱 회사의 부가가치 = 9,900 − 1,200 − 1,000(라이선스) − 2,970(수수료) = 4,730원
- 속성:
  - P1 [G] 중간재 구매 블록이 공급자 노드에서 화살표로 들어옴 — 필수
  - P2 [Q] 블록 높이 금액 비례 — 필수
  - P3 [X] '가상 예시, 앱스토어 수수료는 해외 기업 귀속 시 수입으로 처리' 주석 — 필수, 해외 부문 처리가 결론에 영향
### F7 확장 순환도(4부문)
- 보여 주는 것: F2에 정부(세금·정부구매·이전지출), 금융시장(저축→투자), 해외(수출·수입)를 추가. Y = C + I + G + (X−M) 식의 각 항이 해당 화살표에 연결
- 속성:
  - P1 [G] 누출(저축·세금·수입)은 순환 밖으로, 주입(투자·정부구매·수출)은 안으로 향하는 화살표 — 필수
  - P2 [T] F2에서 새 부문이 하나씩 등장하는 3단계 전개 — 선택, 복잡도를 단계적으로 높임
  - P3 [I] 식의 항을 누르면 대응 화살표 하이라이트 — 필수
  - P4 [E] 이전지출은 생산물과 교환되지 않음을 점선·다른 색으로 구분 — 필수, 퀴즈 오답 원인
  - P5 [X] '화살표 굵기는 비율을 나타내지 않음' 표기 — 필수, 축척 없음을 밝힘
### F8 GDP 포함 여부 분류판
- 보여 주는 것: 카드(구독료 결제, 중고폰 거래, 클라우드 요금, 정부 실업급여, 해외 사용자 구독료, 주식 매수)를 'GDP에 포함/불포함' 두 칸으로 끌어 넣는 분류판, 제출 후 각 카드가 F7의 해당 화살표 위치로 날아감
- 속성:
  - P1 [I] 카드 드래그 앤 드롭 후 채점 — 필수
  - P2 [S] 분류판 옆 F7 축소판 인셋 — 필수, 판정 근거를 구조와 연결
  - P3 [X] 오답 카드에 한 줄 이유(중간재, 이전지출, 기존 자산 이전, 금융 거래) — 필수
