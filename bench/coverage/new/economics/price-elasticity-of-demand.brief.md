# 경제학 · 수요의 가격탄력성과 총수입
## 상황
- 작업: B2C 구독 앱의 월 요금(현재 9,900원)을 올릴지 내릴지 정한다. 학습 자료를 만들어 달라.
- 배경: 스타트업 PM. 수요·공급, 탄력성을 체계적으로 배운 적이 없고, 요금 A/B 테스트 결과(가입자 수 변화)를 매출 판단으로 옮기는 법을 모른다.
## 진단 결과(고정)
- 사다리(낮은 단부터): 수요곡선과 수요량 변화(알고 있음) → 수요량 변화 vs 수요 변화(곡선 이동)(애매함) → 가격탄력성의 정의와 계산(중간점 공식)(애매함) → 탄력성과 총수입의 관계(아예 모름) → 직선 수요곡선 위 탄력성의 변화(아예 모름)
- 학습 수준: 수요량 변화 vs 수요 변화 ~ 직선 수요곡선 위 탄력성의 변화
- 오개념: "가격을 올리면 가입자가 줄어도 단가가 올라가니 매출은 늘어난다"라고 답했다.

## 그림
### F1 요금 인상 전후 매출 막대
- 보여 주는 것: 9,900원×10,000명=9,900만 원과 12,900원×7,000명=9,030만 원의 월매출 막대 두 개, predict 단계에서 학습자가 고른 방향(증가/감소)을 먼저 받고 막대를 공개
- 속성:
  - P1 [Q] 세로축 월매출(만 원), 0에서 시작, 0~10,000 — 필수, 0이 아닌 축은 차이를 과장해 사실과 다른 인상을 준다
  - P2 [I] 막대 공개 전 학습자가 '증가/감소' 중 하나를 선택해야 함 — 필수, 예측 후 공개 구조
  - P3 [X] 막대 아래 '가격 +30.3%, 가입자 −30%' 표기 — 필수, 비율 비교가 다음 단계 정의로 이어짐
  - P4 [E] 차액 −870만 원을 붉은 구간으로 강조 — 필수, 핵심 결론이 먼저 보여야 함
### F2 곡선 위 이동 vs 곡선 이동
- 보여 주는 것: 같은 수요곡선 Q=40,000−3P(P 원, Q 명) 위 점 A(9,900, 10,300)에서 B(12,900, 1,300)로의 이동과, 경쟁사 출시로 곡선이 Q=30,000−3P로 왼쪽 평행이동한 경우
- 속성:
  - P1 [S] 좌우 두 패널 나란히, 축 범위 동일(P 0~14,000원, Q 0~40,000명) — 필수, 같은 축이어야 비교가 사실
  - P2 [G] 왼쪽은 점이 곡선을 따라 움직이는 화살표, 오른쪽은 곡선 전체가 평행이동하는 화살표 — 필수, 두 개념의 구분이 기하로 드러남
  - P3 [T] 왼쪽은 가격 슬라이드에 따라 점 이동, 오른쪽은 곡선 이동이 2초 애니메이션으로 재생 — 선택, 원인(가격 vs 외부 요인) 차이를 동작으로 구분
  - P4 [X] 패널 제목 '수요량의 변화(가격 원인)' / '수요의 변화(가격 외 원인)' — 필수
### F3 변화율 비 분해도
- 보여 주는 것: 가격 변화율과 수요량 변화율을 두 수평 막대로 그리고 그 비가 탄력성임을 보이는 그림 (예: 가격 +26.3%, 수요량 −35.3% → |E|=1.34, 중간점 기준)
- 속성:
  - P1 [Q] 두 막대 같은 % 눈금(−50%~+50%) — 필수, 길이 비가 곧 탄력성
  - P2 [G] 수요량 막대가 가격 막대보다 길면 '탄력적', 짧으면 '비탄력적' 영역 표시 — 필수
  - P3 [X] 공식 |E| = |%ΔQ| / |%ΔP| 를 막대 옆에 표기 — 필수
  - P4 [E] 기준선 |E|=1 을 점선으로 강조 — 필수, 이후 총수입 판정의 경계
### F4 중간점 공식 단계 계산
- 보여 주는 것: (9,900원, 10,000명)→(12,900원, 7,000명)를 중간점 공식으로 계산하는 4단계: ΔQ/평균Q = −3,000/8,500 = −35.3%, ΔP/평균P = 3,000/11,400 = 26.3%, 비 = 1.34, 판정 '탄력적'
- 속성:
  - P1 [T] 단계 버튼으로 한 줄씩 공개, 현재 단계의 숫자가 수요곡선 미니 그림의 해당 구간에 하이라이트 — 필수
  - P2 [Q] 단순 변화율(인상 +30.3%, 인하 −23.3%)과 중간점 변화율(±26.3%)을 비교 표기 — 선택, 방향에 따라 값이 달라지는 문제를 보여줌
  - P3 [X] 각 단계 수식과 숫자 — 필수
### F5 총수입 사각형
- 보여 주는 것: 수요곡선 아래 원점-가격-수량이 만드는 사각형(넓이=총수입). 가격 인상 시 잃는 넓이(수량 감소분×새 가격 이외 영역)와 얻는 넓이(가격 상승분×남은 수량)를 두 색으로 구분
- 속성:
  - P1 [G] 사각형 넓이 = P×Q 가 정확히 축척대로 — 필수, 넓이 비교가 결론이므로 축척을 깨면 안 됨
  - P2 [E] 얻는 사각형(초록, 3,000원×7,000명=2,100만 원) vs 잃는 사각형(빨강, 9,900원×3,000명=2,970만 원) — 필수, 핵심 관계
  - P3 [X] 두 사각형 안에 금액 표기 — 필수
  - P4 [Q] 축 P 0~14,000원, Q 0~12,000명 — 필수
### F6 직선 수요곡선 위 탄력성 탐색
- 보여 주는 것: 직선 수요곡선 Q=20,000−P (P 0~20,000원)와 그 아래 총수입 곡선 TR=P(20,000−P)를 위아래로 정렬. 핸들로 가격점을 끌면 탄력성 값과 TR 위치가 함께 이동
- 속성:
  - P1 [S] 수요곡선(위)과 TR 곡선(아래)이 같은 가격축을 공유하는 세로 정렬 — 필수, 중점과 TR 최대점이 같은 가격임을 눈으로 확인
  - P2 [I] 가격 핸들 드래그(100원 단위) — 필수
  - P3 [Q] 점탄력성 |E| = P/Q 실시간 표시, P=10,000원에서 1, TR 최대 1억 원 — 필수
  - P4 [G] 곡선의 위쪽 절반은 탄력적, 아래쪽 절반은 비탄력적으로 색 구분 — 필수, 기울기가 일정해도 탄력성은 변함
  - P5 [I] 목표: 'TR이 최대가 되는 가격을 찾아라', 도달 시 표시 — 선택
  - P6 [X] 곡선 옆 '예시용 가상 수요' 표기 — 필수, 실제 시장 데이터가 아님을 밝힘
### F7 두 고객군 비교
- 보여 주는 것: 같은 가격 인상(9,900→12,900원)을 학생 고객군(|E|=2.0, 가파르게 이탈)과 업무용 고객군(|E|=0.4)에 적용했을 때의 수요곡선과 총수입 사각형 변화
- 속성:
  - P1 [S] 좌우 small multiples, 동일 축 — 필수
  - P2 [Q] 학생군 기준 5,000명→ 인상 후 약 2,370명, 업무군 5,000명→ 약 4,470명(중간점 기준 일관 계산) — 필수
  - P3 [E] 각 패널의 TR 변화(학생 −1,890만 원대 감소, 업무 +830만 원대 증가) 부호를 색으로 강조 — 필수
  - P4 [X] 탄력성이 다른 이유(대체재 유무, 지출 비중, 필수성) 짧은 라벨 — 선택
### F8 탄력성-총수입 판정표
- 보여 주는 것: |E|>1, =1, <1 세 열 × 가격 인상/인하 두 행의 총수입 방향 화살표 표, 수업에서 계산한 사례 점이 해당 칸에 놓임
- 속성:
  - P1 [G] 각 칸에 위/아래/수평 화살표 — 필수
  - P2 [E] 장면 1 사례(|E|=1.34, 인상→감소) 칸을 하이라이트 — 필수
  - P3 [X] '탄력성은 구간마다 다르므로 테스트 범위 밖으로 외삽 금지' 주석 — 필수, 그림에서 일반화가 과도해지지 않게
