# Intent: Learn while using LLM
Author: Doggy-FP (claims operations). Status: draft.

## Problem
1. LLM tends to decide on behalf of user instead of asking in detail. Thus working with AI agent not knowing some level of details of related stuffs often ends up out of intention
2. Core decisions does not tend to require in depth understanding of the subject. Thus shallow learning and intuitive images can lead to better decisions in core branches.
3. Shallow and wide knowledge can help user's creativity.

## Proposed outcome
1. Anytime user want to learn something, AI agent can give easy-to grasp, aesthetically pleasing, quick to review learning material
2. While working on a task, AI agent might ask user for learning session to decide better. 

## Affected users and systems
1. All users using AI chat & AI agent.
2. Their local environment to keep track of what they've learned.

## Constraints
1. Cost(time/token) verus usual query for learning materials.
2. Quality versus usual query for learning materials. Since this is subjective matter, it's especially hard to tell if this skill works well.

## Open questions
1. How to measure whether a result is good or bad (Constraint 2) beyond the user's human feedback?
2. Target cost (time, tokens) per lesson.
