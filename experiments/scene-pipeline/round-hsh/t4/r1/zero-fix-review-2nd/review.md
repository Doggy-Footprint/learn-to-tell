## 판정 요약
- 실패: 3건 (생성 1, 생성 2, 비트 6). 사실 항목과 화면 결함은 모두 통과.
- 고칠 대상: 생성 1(SSB 추가), 생성 2(프라이머가아제 표기)

## 고친 것
- 생성 1: 분기점 왼쪽 위 주형에 SSB 원 표지를 추가했다(코드 `// 단일가닥결합단백질(SSB)` 줄, 분기점 전진 표지 앞).
- 생성 2: 선도 가닥 프라이머 라벨을 "프라이머"에서 "프라이머가아제"로 바꿨다(코드 56행). 지연 가닥의 "프라이머" 라벨은 그대로 둬 RNA 프라이머 표기를 남겼다.
- 비트 6: 고치지 않았다. 완성된 이중가닥은 새 가닥과 주형을 짝지어 다시 그려야 해서 Edit 범위를 넘는다. 다음 작성 때 최종 프레임 구성을 다시 잡아야 한다.
- audit 1회(고침 0건, 권고 1건 남음: no-signature).
