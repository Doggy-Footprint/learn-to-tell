# direction

## a.html
- 표현: 가로 두 주형 직선(분기점 세로 점선이 오른쪽으로 전진), 아래 캡션이 비트마다 바뀐다. 선도 가닥은 분기점을 따라 늘고, 지연 가닥은 분기점이 열릴 때마다 프라이머 점과 왼쪽(분기점 반대)으로 가는 절편이 추가된다. 마지막에 프라이머가 사라지고 연결선이 생긴다.
- 사실 점검: 절편 순서(오래된 것이 먼 쪽)와 5'→3' 표기는 맞다. 다만 분기점이 선도 가닥과 함께 움직이는 건 좋으나 주형이 두 평행선이라 Y자가 아니다.
- 결함 코드: svg 폭 640 고정에 캡션·라벨이 길어 hscroll·overflow(고침 4건). 라벨 문자열이 길다.

## b.html
- 표현: 왼쪽으로 벌어진 Y자 주형, 선도 가닥은 왼쪽 프라이머에서 분기점으로 연속, 지연 가닥은 분기점 쪽에서 왼쪽으로 절편 3개. CSS 애니메이션 시간표로 순서 재생.
- 사실 점검: Y자, 주형 5'/3' 방향, 새 가닥 방향, 절편 순서(가장 새 것이 분기점 가까이) 모두 맞다. 어긋남: 선도 가닥이 한 번에 쭉 그려져 "분기점을 따라" 자라는 느낌이 약하고, 새 가닥 쪽 5'/3' 표기와 방향 화살촉이 없으며, 연결 단계가 글뿐이다.
- 결함 코드: 없음(audit 고침 0건). 권고만: 프라이머 용어 미표시.

## 가져올 것
- b의 Y자 좌표, 주형·가닥·프라이머 SVG와 CSS 애니메이션 구조 전체, 프라이머 용어 glossary.
- a의 "분기점 전진·절편 누적" 서사는 캡션 문구로만 차용.

## 최종 방향
b의 Y자 도해를 뼈대로 삼는다. 비트: ①닫힌 이중나선에서 두 팔이 열려 Y자가 생긴다 ②선도 프라이머 → 분기점 쪽으로 연속 신장, 끝에 3' 화살촉 ③지연 프라이머 1 → 왼쪽(분기점 반대)으로 절편, 3' 화살촉 ④분기점이 더 열리면 프라이머 2와 절편 2, 이어 프라이머 3과 절편 3(가장 새 것이 분기점 가까이) ⑤절편 하나의 5'→3' 표기와 "분기점과 반대로 자란다" 강조 ⑥프라이머가 사라지고 절편이 이어진 한 가닥. 조작은 없고 자동 재생이며 reduced-motion이면 최종 상태다. 글은 그림 라벨(선도/지연, 5'/3', 분기점, 복제 진행)과 hook 제목·sub 한 줄만 얹는다.
