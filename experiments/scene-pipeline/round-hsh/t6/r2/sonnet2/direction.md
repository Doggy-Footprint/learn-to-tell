# direction

## 초안 a
- 표현: contrast 좌우에 같은 2x2 diagram(x,y → A↔B). 좌우가 각자 player로 따로 넘어가고, 단계마다 highlight와 mono 한 줄(카운트/표시)이 바뀐다.
- 맞는 점: 생성 순서(객체→변수→순환→해제)와 카운트 A2·B2→1·1, mark가 sweep보다 먼저. 해제 한 단계씩 A=1, B=2 중간값까지 보여 계산이 정확하다.
- 어긋난 점: 비트 5(전역 캐시로 붙잡히는 tracing 누수)와 6(진단 질문)이 없다. MS 쪽 단계 수(4)와 RC 쪽(5)이 달라 좌우가 맞물리지 않는다. 카운트가 노드 밖 글줄에만 있어 그림이 숫자를 말하지 않는다.
- 결함으로 보이는 코드: 없음(audit 0건). 다만 단계마다 hold 2400ms로 동일.

## 초안 b
- 표현: 같은 구도지만 MS 쪽에는 x, y 없이 루트 하나와 A, B만 있다. 노드 부제 "참조 카운트"/"표시 안 됨"은 고정 글이라 값이 변하지 않는다.
- 맞는 점: 용어 glossary(참조 카운트, 루트), narration, 근거 문구에 CPython 주의.
- 어긋난 점: x·y 연결 자체를 MS 쪽에서 안 보여 "같은 코드"가 아니다. 카운트가 캡션에만 있다. 전역 캐시 누수 비트 없음. 화면이 86%로 줄었다(narration+sub+foot 과다).
- 결함 코드: 노드 부제가 정적이라 단계와 그림이 어긋난다. 엣지 label이 x·y 등 중복 정보.

## 가져올 것
- a: 같은 2x2 구도(x,y 왼쪽, A,B 오른쪽)와 해제 중간 단계 계산, contrast 구조·foot·takeaway.
- b: glossary(참조 카운트·루트) 아이디어와 basis의 CPython 주의 문구.

## 최종 방향
그림의 뼈대는 contrast 좌우에 같은 격자 diagram 두 개(참조 카운팅 / mark-and-sweep)이고, 하나의 stepper가 두 쪽을 동시에 넘긴다. 노드 부제가 단계마다 바뀌어 숫자가 그림에 직접 얹힌다. 비트: ①A, B가 생긴다(카운트 0 / 표시 —) ②x→A, y→B가 생긴다(1,1) ③A↔B 순환이 생긴다(2,2) ④x, y가 해제되어 연결이 사라진다(1,1 / 루트 비어 있음) ⑤RC: A, B가 bad로 남고 retainer는 서로뿐·루트 경로 0 / MS: mark가 돌아 A, B 미표시 ⑥MS: sweep이 A, B를 해제 ⑦MS 쪽만 바뀐다: 루트→전역 캐시→C(순환 없음)가 표시된 채 남는다. 마지막 단계는 진단 질문으로 닫는다: 경로가 있으면 첫 retainer를 끊고, 없으면 순환 retainer를 끊거나 약한 참조로 바꾼다. 조작은 이전/다음/반복 재생. 글은 단계 자막, 쪽별 mono 상태 한 줄, foot, takeaway만 둔다.
