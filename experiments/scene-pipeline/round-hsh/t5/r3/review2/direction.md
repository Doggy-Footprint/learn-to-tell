# direction

## 초안 a
- 표현: 라운드마다 diagram(예금 → 대출 → 다음 예금, 예금 → 준비금)을 갈아끼우고, 아래에 누적 막대 차트(준비금 + 새 예금 쌓임)와 r별 천장 점선 3개를 둔다. 손잡이는 r(5·10·20%) steps. 3박자(예금 → 준비금·대출 → 다음 예금) 자동 재생.
- 맞는 점: 생성 순서(예금 → 대출 → 새 예금), 누적이 한 칸씩 쌓임, 천장 3개 비교, 준비금 100 점선.
- 어긋난 점: 그림이 둘(작은 diagram + 차트)로 쪼개져 가장 큰 그림이 화면의 6%뿐(small-visual), 글 때문에 78%로 축소(shrunk). 막대 높이가 y축 2100에 맞춰 r=20%에서는 작아 보인다.

## 초안 b
- 표현: 라운드 체크포인트(1·2·3·5·10·30)를 단계 자막으로 넘기며 r별 누적 곡선 3개가 자라고 천장 점선이 있다.
- 맞는 점: 수치(271, 409.5, 651, 958)와 천장 비교. 어긋난 점: 대출 → 예금 연쇄, 준비금 대비 예금 증가가 그림에 직접 안 보이고 곡선만 있다. 3개 r이 동시에 자라 "r을 바꾸면" 흐름이 없다. 조작 없음.
- 화면 결함 후보: hero 숫자가 곡선과 떨어져 있음, 글꼴 8단계(many-sizes).

## 가져올 것
- a: r steps 손잡이, 3박자 재생, 천장 3줄 중 선택 강조, 준비금 100 점선, rounds() 모델.
- b: 천장 3개를 항상 함께 두는 비교, 캡션식 짧은 문장.

## 최종 방향
그림 하나: 왼쪽은 라운드 폭포(행마다 예금 막대가 준비금 + 대출로 갈라지고, 대출 끝에서 화살표가 다음 행의 새 예금으로 내려간다), 오른쪽은 총예금 탑(라운드가 끝날 때마다 그 라운드 예금이 한 칸 쌓이고, 옆 준비금 기둥은 100억 쪽으로만 자란다). 탑 위에 r 5·10·20%의 천장선 3개를 놓고 선택한 것을 강조한다. 비트: 예금 막대 생성 → 준비금/대출 분할 → 대출이 다음 행 예금이 되며 탑에 한 칸 쌓임 → 반복(6라운드 뒤는 빠르게) → 천장 근처. 조작은 r steps 손잡이로, 바꾸면 처음부터 다시 재생되고 천장이 달라진다. 글은 숫자 hero 두 개(예금 합계, 준비금 합계)와 짧은 narration, 마지막에 "이론상 상한" 근거.
