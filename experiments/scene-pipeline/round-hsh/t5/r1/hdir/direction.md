# 방향: 신용 창조 한 그림 (ledger, figure 장면)

## 1. 초안 점검

- **a.html**: 왼쪽 라운드 막대(준비금 아래, 대출 위 스택)와 오른쪽 누적 선을 한 SVG에 담았다. 다음 라운드 예금을 반투명 유령 막대로 먼저 보여 줘 "대출 → 새 예금" 인과가 드러난다. 수치(271, 409.5, 상한 1000)는 맞다. 감사 고침 0건. 결함: 한 장면에 단계가 8개라 자막이 길고, 500 기준선이 누적 점과 겹칠 여지가 있다.
- **b.html**: 좌 라운드 막대, 우 30라운드 누적 곡선. 30라운드 점선으로 상한 근처에서 평평해지는 모습이 좋다. 그러나 막대는 5라운드만 보이고 단계 재생이 없다. 감사: 설명 레일(narration) 때문에 split 레이아웃이 되어 그림이 화면의 19%뿐이다(고침 권고).
- **c.html**: 6라운드 막대와 누적 점을 단계마다 보여 준다. 결함: 단계 n에서 라운드 n의 준비금과 대출이 한꺼번에 나타난다. "대출금이 다음 예금이 되는" 순서가 화면에서 생략된다. 감사 고침 0건.
- **d.html**: 지급준비율 버튼(5/10/20%)과 자동 재생이 있다. 재생 순서가 생성 순서와 맞다: 예금 등장 → 준비금·대출로 갈라짐 → 다음 라운드 예금 → 누적 점. 반복 재생은 leave에서 멈추고 reduced-motion이면 최종 상태를 보인다. 결함: 그림 아래 글이 길어 화면이 78%로 줄었다(권고).

## 2. 가져올 것

- **d.html**: mount 골격, 버튼으로 r 바꾸기, 단계 재생과 `leave`/reduced-motion 처리, 생성 순서. 이 뼈대를 쓴다.
- **a.html**: 다음 라운드 예금을 반투명 유령 막대로 먼저 보이는 방식. d의 `cc-dep` 단계에 옮긴다.
- **c.html**: 누적 점 옆의 수치 라벨(`cumLabel`) 방식.
- 버린 것: b의 30라운드 곡선(화면을 넓힌다), c의 한꺼번에 나타나는 단계.

## 3. 최종 방향

**그림의 뼈대**: 한 SVG, 두 패널. 왼쪽은 라운드별 새 예금 막대 6칸(1~5라운드 + 상한 점선 아래에 머무는 칸), 각 막대는 준비금(c1, 아래)과 대출(c2, 위)로 나뉜다. 오른쪽은 누적 예금 선과 상한 점선(r에 따라 이동, 라벨 "상한 = D0 ÷ r").

**비트별 움직임** (재생 순서 = 생성 순서):
1. 최초 예금 100이 첫 칸에 회색 덩어리로 나타난다.
2. 덩어리가 준비금 10(아래)과 대출 90(위)으로 갈라진다.
3. 대출 90이 다음 칸에 반투명 유령 막대로 "다음 예금 90"을 만든다.
4. 유령이 실체가 되어 같은 방식으로 갈라진다(9 / 81).
5. 누적 점이 찍히고 선이 자란다(누적 수치 라벨 표시).
6. 2~5를 라운드 6까지 반복한다. 막대는 점점 짧아지고, 선은 상한 점선을 향한다.
7. 상한 점선과 "상한 1000 = 100 ÷ 0.1" 라벨을 강조한다.

**조작**: 지급준비율 버튼 5% / 10% / 20%. 바꾸면 상한 점선이 옮겨지고(5%: 2000, 20%: 500) 재생이 처음부터 다시 돈다. 승수 1/r과 상한을 하단 한 줄로 보인다.

**글**: 제목(주장 문장) "대출금이 다시 예금이 되면서, 처음 예금은 1/지급준비율 배로 불어난다". 자막 한 줄. 단계마다 그림 아래 한 줄(`#cc-line`)이 "준비금 X을 남긴다 / 나머지 Y를 대출한다 / 이 돈은 다음 예금이 된다"를 말한다. takeaway와 recall은 기존 것을 쓴다. basis에 이론적 상한과 "모델로 계산한 예시" 태그를 둔다.

**화면 조정**: 감사 권고(78% 축소)를 줄이기 위해 SVG viewBox 높이를 줄이고, 자막과 stats 줄을 합치며, 설명 문장을 짧게 한다.
