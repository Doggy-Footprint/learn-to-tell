# direction

## 초안 a
뼈대: 루트-N2-리프 줄 트리 SVG 하나. 노드가 위치를 보간하며 이동하고 선은 매 프레임 다시 그린다. 5단계(꽉 찬 상태 → 리프 5키 → 리프 분할+N2 초과 → N2 분할+루트 초과 → 루트 분할+새 루트, 깊이 +1). 조작은 단계 재생. 점검표와 일치: 25 복사/60·200 이동, 오른쪽 형제, 새 루트가 맨 위, 모든 리프 깊이 +1, 25 삽입 표시. 결함 코드 없음(audit 0건). 약점: 높이 표시 없음, 위로 올라가는 키가 노드 안 글로만 보임.

## 초안 b
뼈대: 같은 트리, 노드 CSS transition으로 이동, 간선은 매 단계 새로 그림, 리프 형제 링크는 x순 정렬로 자동 생성, "트리 높이 3→4" 라벨. 생성 순서·복사/이동 모두 맞음. 약점: 간선이 단계마다 바뀌어 애니메이션 없이 튐, 새 루트가 N2 위치 계산이 겹침 위험, 올라가는 키 강조 없음.

## 가져올 것
a: 노드 보간·선 추적 구조, 단계 데이터, 캡션. b: "트리 높이" 라벨, 단계 캡션의 "경로 세 노드가 모두 4키" 문장.

## 최종 방향
뼈대는 a의 트리 도해. 비트: ①25 삽입 위치와 꽉 찬 경로 3노드 → ②리프 5키 초과 → ③리프 분할(오른쪽 형제 생성, 25 복사)과 N2 초과 → ④N2 분할(60 이동)과 루트 초과 → ⑤루트 분할, 200 상승, 새 루트가 맨 위에 생기고 전 리프 깊이 +1, 높이 라벨 3→4. 조작은 단계 이동(덱 steps). 글은 짧은 캡션과 takeaway, 페이지 크기(팬아웃)는 basis에.
