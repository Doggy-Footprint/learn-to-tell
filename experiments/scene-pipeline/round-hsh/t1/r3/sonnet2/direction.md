# direction

## 초안 a
커스텀 SVG 한 장에 노드(키 칸)를 그리고 단계마다 다시 배치한다. 잎 사이 형제 포인터를 점선 곡선으로 그리고, 5단계(초과 → 잎 분할 → 루트 초과 → 루트 분할+새 루트 → 높이 3)로 나눈다. 사실은 대체로 맞다(복사/이동 구분, 2+3 분할, 2키씩 내부 노드). 어긋남: 2단계에서 "50이 부모로 올라간다"고 하면서 루트에는 50이 보이지 않아 위로 올라가는 순서가 그림에 없다. 3단계에서 루트-새 잎 연결이 이미 있다. 4단계에 갈라진 내부 노드와 새 루트가 한 번에 나온다(새 루트는 가장 마지막이어야 함). audit은 고침 0건, 화면 결함 코드는 눈에 띄지 않는다. 조작은 단계 넘기기뿐.

## 초안 b
LTT.diagram 격자에 손 계산 상태를 모두 노드로 두고 단계마다 보일 것만 필터한다. 구분 키 복사를 점선 간선으로 보이고 패킷을 보낸다. 상태 순서와 사실은 맞다. 화면 결함: 손으로 정한 좌표라서 간선·라벨이 5곳 겹침(graph-overlap 고침 2건). 6개 부모 간선이 한 노드에서 부채처럼 나가 읽기 어렵다.

## 가져올 것
a의 SVG 노드 렌더링·형제 포인터 곡선·audit 통과한 구조를 쓴다. b의 "복사 올림을 점선으로 이으며 라벨을 붙이는" 아이디어를 가져와, 구분 키가 아래에서 위로 올라가는 순서를 단계로 분리한다.

## 최종 방향
그림 뼈대는 3층 B+tree 한 장(루트/내부/잎, 잎 사이 점선 형제 포인터). 비트: ① 52가 가득 찬 잎에 들어가 5키로 넘침(빨간 틀) → ② 새 오른쪽 잎 [50 52 55]가 먼저 생기고 왼쪽 [40 45]로 갈라짐, 루트는 아직 그대로 → ③ 50이 점선으로 루트에 복사되어 올라가 루트가 5키로 넘침(잎에도 50 남음) → ④ 루트가 두 내부 노드 [20 40], [60 80]로 갈라지고 가운데 50은 이동해 떠 있음(어느 노드에도 안 남음) → ⑤ 맨 마지막에 [50] 새 루트가 위에 생기고 모든 잎이 깊이 3. 조작은 단계 넘기기. 글은 단계 자막, 해설(복사 vs 이동, 8KB 페이지 팬아웃 ~500이면 3층 약 1.25억 키), basis로 규모 근거를 얹는다.
