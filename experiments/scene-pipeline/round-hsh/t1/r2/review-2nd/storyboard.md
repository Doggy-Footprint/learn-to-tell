# 스토리보드: B+tree 노드 분할이 루트까지 전파

role=figure · theme=blueprint · medium=DB 내부 구조 도해 · 독자=백엔드 개발자 · 결정=인덱스 설계와 페이지 크기 이해

## 독자가 스스로 말할 한 문장
"꽉 찬 잎에 키를 넣으면 잎이 쪼개지고, 부모도 꽉 차 있으면 위로 쪼개짐이 이어지다가, 루트가 쪼개질 때만 트리가 한 층 높아진다. 그래서 페이지가 클수록 팬아웃이 커서 트리가 낮다."

## 인과 사슬
1. 꽉 찬 잎(페이지)에 키가 들어와 용량을 넘긴다 (overflow).
2. 잎이 둘로 나뉜다. 새 오른쪽 잎이 생기고, 구분 키 하나가 부모에 올라간다.
3. 부모가 이미 꽉 차 있으면 그 구분 키 때문에 부모도 넘치고, 같은 방식으로 쪼개진다.
4. 넘침은 꽉 찬 조상이 있는 만큼만 올라간다. 꽉 차지 않은 조상을 만나면 거기서 멈춘다.
5. 루트까지 넘치면 루트가 쪼개지고 새 루트가 생긴다. 높이 +1은 이때뿐이다.

## 화면에 꼭 보일 것
- 높이 3 트리: 루트 → 내부 노드 → 잎. 잎들은 옆으로 연결 리스트로 이어진다.
- 경로상의 세 노드(잎, 내부 노드, 루트)가 모두 꽉 찬 상태.
- 각 노드가 키 칸 몇 개짜리 페이지인지(용량).
- 강조점 하나: 쪼개짐 때 위로 올라가는 구분 키와, 마지막에 새 루트가 생겨 모든 잎이 한 층씩 내려가는 순간.

## 구체 예 (노드당 키 최대 4개, 자식 최대 5개)
시작: 루트 [50 100 150 200](꽉 참). 그 둘째 자식 I2 [60 70 80 90](꽉 참). I2 아래 잎 L [81 83 85 88](꽉 참). 키 **86** 삽입.
- 잎: [81 83 85 86 88] 5개 → 넘침. 왼쪽 [81 83 85], 오른쪽 [86 88]. 구분 키 86은 **복사**되어 올라간다(오른쪽 잎에도 남는다).
- I2: 86이 80과 90 사이에 들어가 [60 70 80 86 90] 5개(자식 6) → 넘침. 가운데 키 80을 위로 **이동**: 왼쪽 [60 70], 오른쪽 [86 90]. 80은 I2 쪽 어디에도 남지 않는다.
- 루트: 80이 50과 100 사이에 들어가 [50 80 100 150 200] 5개(자식 6) → 넘침. 가운데 100이 위로 이동: 왼쪽 [50 80], 오른쪽 [150 200]. 새 루트 [100].
- 결과: 높이 3→4. 손 검산: 루트 자식 5개 중 I2가 둘로 늘어 6개 = 새 왼쪽 3 + 오른쪽 3. 키 합계도 맞는다(루트 4개+삽입 1개 = 5 = 왼쪽 2 + 올라간 1 + 오른쪽 2).

## 생성 순서 (틀리기 쉬움)
- 아래에서 위로. 각 단계에서 새 **오른쪽 형제**가 먼저 생기고, 그다음 구분 키가 부모에 들어가고, 그 뒤에야 부모의 넘침을 판단한다.
- 새 루트는 **맨 마지막**에 생긴다. 그 순간 이전의 루트가 둘로 갈라진 두 노드가 새 루트의 자식이 된다.
- 잎 연결 리스트: 새 잎은 L → 새 잎 → 원래 L의 다음 잎 순으로 끼어든다.

## 사실 점검표
- 잎 분할은 구분 키를 **복사**(B+tree는 모든 키가 잎에 남아야 한다), 내부 노드 분할은 가운데 키를 **이동**한다.
- 키 5개 분할: 잎은 3+2, 내부는 2+(위로 1)+2. 자식 수는 3+3.
- 모든 잎의 깊이는 항상 같다. 한쪽만 깊어지지 않는다.
- 높이는 루트가 쪼개질 때만 늘고, 잎이 쪼개질 때는 늘지 않는다.
- 팬아웃 ≈ 페이지 크기 ÷ 항목 크기: 8192 B ÷ 16 B = 512(헤더 감안 약 500). 높이 3이면 약 500³ ≈ 1.25억 키. 페이지 4 KB면 팬아웃 약 250, 같은 높이에 약 1,560만 키(250³).

## 흔한 오해와 깨는 순간
오해: "삽입하면 BST처럼 잎 아래로 가지가 자라 트리가 깊어진다." 또는 "분할이 일어나면 매번 루트까지 간다."
깨는 순간: 잎이 쪼개져도 높이는 그대로이고, 루트가 쪼개질 때만 새 루트가 위에 생겨 모든 잎이 동시에 한 층 내려간다. 또 팬아웃이 약 500이면 부모가 꽉 찰 확률이 낮아, 연쇄는 보통 한 단계에서 멈춘다.

## 비트
1. 높이 3 트리에서 삽입 경로의 잎·내부 노드·루트가 모두 꽉 차 있다.
2. 키 86이 꽉 찬 잎에 들어와 5개가 되고 잎이 3+2로 갈라진다. 86이 오른쪽 잎에 남은 채 복사되어 올라간다.
3. 부모도 넘쳐 가운데 80이 올라가고 사라진다(복사와 이동의 차이).
4. 루트가 넘쳐 100이 올라가 새 루트가 생기고, 모든 잎이 같이 한 층 내려가 높이가 4가 된다.
5. 같은 삽입이 꽉 차지 않은 부모에서는 한 번 분할로 멈추는 모습을 대비한다.
6. 페이지 크기(8 KB vs 4 KB)에 따라 팬아웃이 달라져 같은 키 수에서 높이가 달라진다.
