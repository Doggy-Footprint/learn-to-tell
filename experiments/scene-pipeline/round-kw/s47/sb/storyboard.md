# 스토리보드: 국가별 전력 믹스 (sweep)

- 주제: 에너지 · 연도별 지역 전력 믹스 / 독자: 에너지 정책 입문자 / 매체: 에너지 통계 차트 / 결정: 전원 구성 비교

## 독자가 말할 수 있어야 할 한 문장
"나라마다 전기를 만드는 전원의 비율이 다르고 같은 나라도 해마다 달라지지만, 비중(%)은 합이 100이라서 총 발전량(TWh)을 함께 봐야 전원 구성을 제대로 비교할 수 있다."

## 인과 사슬
1. 자원 여건(석탄·가스 매장, 수력 지형, 일사·풍황)과 정책(원전 유지·폐지, 탄소 가격, 보조금)이 각국의 전원 투자를 정한다.
2. 투자가 쌓여 발전설비(GW)가 되고, 설비는 이용률(capacity factor)만큼만 발전량(TWh)이 된다.
3. 발전량을 전원별로 나눈 것이 믹스(%)다. 믹스가 달라지면 전력 1kWh당 탄소배출(g CO2/kWh)도 달라진다.
4. 연도를 훑으면(sweep) 신규 설비·폐쇄·수요 증가가 누적된 결과로 믹스가 서서히 이동한다.

## 화면에 꼭 보일 것
- 대상: 국가(또는 지역), 연도, 전원별 발전량 구성(석탄·가스·원자력·수력·풍력+태양광·기타).
- 관계: 같은 연도에서 국가 간 구성 비교, 같은 국가에서 연도 간 구성 변화. 비중의 합은 항상 100%.
- 강조점 하나: 연도를 훑을 때 한 전원(풍력+태양광)이 커지는 만큼 다른 전원의 비중이 줄어드는 모습.

## 사실 점검표
- 단위: 발전량은 TWh(또는 %), 설비용량은 GW. 둘을 섞지 않는다. 1 GW × 8,760h = 최대 8.76 TWh.
- 이용률 대략: 원자력 ~90%, 석탄 ~50~60%, 가스 ~40~55%, 육상풍력 ~25~40%, 태양광 ~12~25%. 그래서 설비 비중 ≠ 발전 비중.
- 비중 합 = 100%. 반올림으로 99~101이 될 수 있으면 각주로 밝힌다.
- 전력 믹스 ≠ 1차에너지 믹스. 전기는 최종에너지의 약 20% 수준이다. 이 장면은 발전(생산) 기준이며 수출입·소비 기준이 아니다.
- 수명주기 배출계수(IPCC 중앙값, g CO2eq/kWh): 석탄 ~820, 가스 ~490, 태양광(대규모) ~48, 수력 ~24, 원자력 ~12, 육상풍력 ~11.
- 손 계산 예시 (가상 국가 A, 총 500 TWh): 석탄 200, 가스 100, 원자력 100, 수력 50, 풍력+태양광 50
  - 비중 = 40 / 20 / 20 / 10 / 10, 합 100%.
  - 배출강도 = 0.40×820 + 0.20×490 + 0.20×12 + 0.10×24 + 0.10×30(풍력·태양광 평균 근사) = 328 + 98 + 2.4 + 2.4 + 3 ≈ 434 g/kWh.
  - 총배출 ≈ 434 g × 500 TWh(=5,000억 kWh) ≈ 2.17억 t CO2eq.
- 비중 vs 총량 예시: 1년차 총 400 TWh 중 석탄 200 (50%), 5년차 총 600 TWh 중 석탄 200 (33%). 비중은 17%p 줄었지만 석탄 발전량은 그대로다.

## 흔한 오해와 깨는 순간
- 오해: "재생에너지 비중이 올라갔으니 화석연료 발전은 줄었다."
- 깨는 순간: 위 예시처럼 석탄 비중이 50%→33%로 내려가는 동안 석탄 발전량(200 TWh)은 변하지 않았음을 총량과 나란히 확인할 때. 비중이 줄어든 원인은 석탄 감소가 아니라 분모(수요) 증가다.

## 비트
1. 한 나라·한 연도의 구성이 전원별 비중으로 나뉘고, 합이 100%임을 알아차린다.
2. 같은 연도에 나라를 바꾸면 구성이 크게 다르다(석탄 중심 / 원전·수력 중심 / 가스 중심)는 것을 알아차린다.
3. 한 나라에서 연도를 훑으면 풍력+태양광이 커지고 그만큼 다른 전원의 비중이 밀려나는 것을 알아차린다.
4. 비중이 줄어든 전원이 발전량(TWh)으로는 줄지 않았을 수 있음을, 총량이 커진 구간에서 알아차린다.
5. 구성 차이가 kWh당 배출강도 차이(예: 약 434 g/kWh 대 훨씬 낮은 값)로 이어짐을 알아차리고, 비교 기준(비중·총량·단위)을 함께 보게 된다.
