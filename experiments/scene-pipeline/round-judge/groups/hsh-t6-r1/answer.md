**나** 객체를 만드는 순서(A=1 → B=1 → A=2 → C → 끊기)를 단계마다 정확히 보여 준다. 생성 순서 표현은 가장 충실하다. 하지만 그래프가 좁은 패널 안에 작게 갇혀 있고 패널 오른쪽 절반이 비어 있어서, 그림이 화면의 주인공이 되지 못한다. 프로파일러 결과도 한 줄뿐이다.
