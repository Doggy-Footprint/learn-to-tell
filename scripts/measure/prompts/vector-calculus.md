## 상황
- 작업: Mathematics for Machine Learning 5장(Vector Calculus)을 공부하며 NumPy로 은닉층 하나짜리 MLP의 역전파를 손으로 짠다. 각 기울기(가중치 행렬, 편향, 입력)의 모양과 곱하는 순서를 정해야 하고, 수치 미분으로 맞는지 확인해야 하는데 판단 근거를 모른다. 학습 자료를 만들어 달라.
- 배경: AI 대학원 1년차. 행렬 곱과 스칼라 함수의 미분, 연쇄 법칙(스칼라)은 안다. PyTorch autograd를 써 봤지만 안에서 무엇을 하는지는 모른다.

## 진단 결과(고정)
- 사다리(낮은 단부터): 편미분과 기울기를 행 벡터로 쓰는 관례(애매함) → 벡터 함수의 Jacobian과 그 모양(이름만 앎) → 다변수 연쇄 법칙: Jacobian의 곱과 곱하는 순서(애매함) → 행렬에 대한 기울기와 모양 맞추기(아예 모름) → 역전파와 역방향 자동 미분(이름만 앎).
- 학습 수준: 다변수 연쇄 법칙. 편미분과 기울기는 애매함이라 수업에 일부 넣는다.
- 오개념: "연쇄 법칙은 미분값을 곱하기만 하면 되니 곱하는 순서와 모양은 상관없다"고 답했다.
