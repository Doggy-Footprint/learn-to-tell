# 브라우저 진단 페이지(카드 + 4가지 반응)

## Context
v0(2026-10-03 ~ 10-08)는 진단을 브라우저 페이지에서 했다. 페이지가 카드를 보이고 사용자가 4가지 반응 중 하나를 골랐다. 사용자 피드백을 받아 v0 안에서 진단을 대화로 옮겼고, 2026-10-13 재작성(ADR 06a89373)도 대화 진단을 유지했다. 이 기록은 `learn-to-tell-PROJECT.md`의 옛 7장 "폐기한 설계와 이유"(commit `b7ded9d`)에서 옮겼다.

## Rejected Alternative
진단을 브라우저 페이지로 진행한다. 페이지가 개념 카드를 보이고 사용자는 카드마다 4가지 반응 중 하나를 고른다.

## Reason
모르는 상태에서 카드에 반응하려면 "내가 아는 개념인지"를 되물어야 한다. 페이지에는 되물을 경로가 없었다.

## Revisit Condition
대화 없이 진단해야 하는 호스트를 지원 범위에 넣을 때. 또는 브라우저 페이지에서 사용자가 카드마다 질문을 보내고, agent의 답을 받은 뒤 같은 카드에 응답할 수 있게 될 때.

## Chosen Instead
