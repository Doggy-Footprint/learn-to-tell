# 상황 카드로 바로 시작하는 진단

## Context
v0 진단은 처음에 상황 카드로 바로 시작했고, 나중에 개념 사다리를 먼저 묻는 방식으로 바뀌었다. 2026-10-13 설계(`learn-to-tell-PROJECT.md` 3장 진단)에는 상황 카드 단계가 없다. 학습 수준은 개념 사다리만으로 정한다. 사다리는 3–5단이고 중간 단부터 묻는다. 각 단을 묻기 전에 개념의 뜻, 이 상황에서 필요한 이유, 한 줄 예시를 먼저 보인다. 이 기록은 `learn-to-tell-PROJECT.md`의 옛 7장 "폐기한 설계와 이유"(commit `b7ded9d`)에서 옮겼다.

## Rejected Alternative
진단의 첫 질문으로 작업 상황을 담은 카드(상황 카드)를 보이고 사용자의 반응을 받는다.

## Reason
- 상황 카드에 낯선 용어가 곧바로 나와 사용자가 대처하기 어려웠다.
- 모든 카드에 "모름"으로 답하면 사용자가 어느 수준까지 아는지 구분되지 않았다.

## Revisit Condition
- `result.md` 기준 최근 10편 중 3편 이상에서, 사다리로 정한 학습 수준 아래 개념이 이해 확인 퀴즈에서 fail일 때. 이 경우 사다리 뒤에 상황 카드 단계를 다시 넣을지 검토한다.

## Chosen Instead
skills/learn-to-tell/SKILL.md (§1 진단: 개념 사다리, 상황 카드 단계 없음)
