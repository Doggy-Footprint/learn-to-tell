# 수업 범위를 사용자에게 확인받는 단계

## Context
v0는 수업 범위를 정한 뒤 사용자에게 확인받는 단계를 거쳤다. 2026-10-13 설계에서는 agent가 결정 변수, 개념, 다루지 않을 부분을 정하고 사용자에게 알리기만 한다. 이 기록은 `learn-to-tell-PROJECT.md`의 옛 7장 "폐기한 설계와 이유"(commit `b7ded9d`)에서 옮겼다.

## Rejected Alternative
agent가 이번 수업의 결정 변수, 개념, 다루지 않을 부분을 제안하고, 사용자가 승인한 뒤에 자료를 만든다.

## Reason
사용자에게는 범위가 맞는지 판단할 근거가 없었다. 아직 그 개념을 모르는 상태에서 받는 질문이었다.

## Revisit Condition
범위 알림을 받은 사용자가 범위를 바꿔 달라고 요청한 수업이 최근 10편 중 3편 이상일 때.

## Chosen Instead
skills/learn-to-tell/SKILL.md (§2 범위 첫 항목), learn-to-tell-PROJECT.md (3장 범위)
