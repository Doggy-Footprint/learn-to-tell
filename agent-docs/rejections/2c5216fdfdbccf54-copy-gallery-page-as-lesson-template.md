# 가장 비슷한 gallery 페이지를 복사해 수업을 만드는 방식

## Context

수업 HTML을 만드는 방법으로, agent가 `ltt-meta`로 가장 비슷한 gallery 페이지를 골라 복사한 뒤 장면 데이터만 고치게 했다(SKILL.md 3단계, c7904b7–b6a39a7).

## Rejected Alternative

gallery 페이지를 템플릿으로 복사해 데이터만 바꾸는 방식.

## Reason

사용자가 "하나의 html 탬플릿을 복사해서 쓰는 건 내가 원하는 방향이 아니야. 내가 원한 건 라이브러리를 제공하는 거야"라며 거부했다.

## Revisit Condition

라이브러리 조합 방식으로 만든 수업이 반복해서 같은 구조로 수렴해, 조합 비용만 늘고 차이가 없다고 확인될 때.

## Chosen Instead

skills/learn-to-tell/kit/API.md, skills/learn-to-tell/look/look.md (shot 코드는 읽지 않고 카드의 원리만 옮긴다)
