# SKILL.md 전체 재설계 계획 (Design Principles 기준)

상태: 사용자 검토 대기. 브랜치 `education-first`. 기준: AGENTS.md "Design Principles", ADR `6ff15ad3eef7b88d`.

kit·도구 쪽 단계는 `eff0795231314dc5-kit-auxiliary-screenshot-check.md`의 1–4단계를 그대로 쓴다. 그 계획의 5단계(SKILL.md §3 재작성)는 이 계획의 R2에 흡수한다.

세션 분리(`/fork` 대신 백그라운드 생성 agent)는 issue #16으로 넘겼다. 이 계획은 다루지 않으며 §0의 `/fork` 흐름과 §5의 원래 세션 복귀는 현행대로 둔다.

## 바뀌는 흐름

| 절 | 현행 | 재설계 |
|---|---|---|
| §0–§1 | 변경 없음 | 변경 없음. 학습 진행 여부는 사용자에게 묻고, 동의하면 storyboard를 준비한다 |
| §2 범위 | agent 우선 결정, 필요하면 질문 | 유지. `outline.md`에 학습자 평가 기준을 여기서 적는다 |
| §3 생성 | outline → 검토 서브에이전트 → storyboard → lesson → audit → 판정 서브에이전트 | 한 agent가 계획 → `checklist.md` → storyboard → lesson → 스크린샷을 한다. 검증 서브에이전트 하나가 `checklist.md`와 스크린샷만 보고 만족하지 않는 항목만 보고한다 |
| §4 이해 확인 | 대화 | 유지. 판정은 `outline.md` 평가 기준을 쓴다 |
| §5 복귀 | `result.md` + 원래 세션에 보고 | 생성 비용의 서브에이전트 항목을 "검증 n회"로 바꾼다 |
| §6 map | 변경 없음 | 변경 없음 |
