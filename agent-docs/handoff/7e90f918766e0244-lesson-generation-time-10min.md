### 시간을 늘린 원인(수업 보고와 측정에서)

- **검증 서브에이전트만 잡은 결함이 다음 회차를 만든다.** 빈 predict 버튼(결함 4), 넘침·겹침·작은 글자(결함 2), 공개 전 takeaway(결함 6)는 audit check 0으로 통과한 뒤 검증에서 걸려 회차가 늘었다. vector-calculus는 3회차 모두 이 부류로 8 → 8 → 4건이었다.
- **audit 출력에 없는 lint 경고(결함 1).** 경고는 스크린샷 속 패널로만 보여, 에이전트가 shot을 열어 읽은 뒤 고치고 audit을 다시 돌렸다. 패널이 그림을 가려 검증 회차도 늘었다(llm, retrieval, diversification, investing 보고).
- **개념 나무·덱 순서 충돌(결함 3, 7).** lint 경고 → 장면 이동 → 체크리스트 번호 수정 또는 미충족으로 audit·검증이 1회 이상 더 돌았다(14개 수업).
- **audit이 원인을 안 보여 준 디버깅(결함 9, 10).** art·ontology는 빈 페이지 원인을 찾으려고 임시 서버와 headless Chrome을 직접 띄웠다. drawing은 `getTotalLength()` 0 원인 찾는 데 검증 2회를 썼다. projectile은 sweep 예외가 뒤 장면 clock을 죽여 `shot-unknown-clock`만 보였다.
- **검증 불가 항목(결함 5).** 공개 상태·steps 뒷단계 항목은 몇 회차를 돌려도 충족될 수 없는데 회차를 소모했다(color, anchoring, tls, drawing).
- **문서 탐색.** predict 형식·`LTT.sweep` 사용법이 허용된 네 절에 없어 "조합 조각"을 grep했다(결함 4, 13). SKILL.md 19,804 B + API.md 16,335 B + `kit/api/*.md`(합계 85,464 B)를 상황에 따라 읽는다.
