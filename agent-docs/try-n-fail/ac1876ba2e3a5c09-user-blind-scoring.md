# 장면 품질을 사용자 본인의 블라인드 채점으로 판정

## Goal
장면 생성 실험의 갈래(본보기 유무, 샘플·검수 단계 등)를 사용자 관점의 품질로 비교한다. 방법은 사용자가 장면 묶음을 블라인드로 직접 채점하는 것이다.

## Attempts
| attempt | failure evidence | cause |
| --- | --- | --- |
| 키워드 실험: 사용자가 10묶음 × 3장면(원본, K, 0)을 블라인드로 10점 만점 채점(`experiments/scene-pipeline/round-kw/db/`, `round-kw/db2/`) | 채점은 끝냈다. 사용자: "갤러리를 알고 있어서 오염이 좀 있을 수 있는데, 일단 무시해도 좋을 것 같아" | user rejected: 이미 본 gallery에 익숙해 평가가 달라진다 |
| HSH 실험: 사용자가 18묶음 × 6장면(108장면)을 블라인드로 채점(`experiments/scene-pipeline/round-judge/user-hsh.json`) | 13묶음(78장면, t1–t5 r2)에서 멈춤. t2-r1은 평가 불가. 사용자: "나 이거 힘드렄ㅋㅋㅋㅋ 이거 t5 까지만 하고, LLM-as-a-judge 만들자." | user rejected: (1) 채점에 시간이 너무 든다. (2) 채점하는 동안 피로와 장면에 대한 익숙함으로 평가 기준이 바뀐다 |

## Revisit Condition
- 기존 LLM-as-a-judge(handoff `8712abeff5bd7bee`의 사용자 관점 채점관)를 보완해야 할 때. 예: 채점관 점수가 사용자 판단과 어긋나는 사례가 보고돼 보정·검증용 사람 점수가 더 필요할 때. 이때 사람 채점은 채점관을 대체하지 않고 기준값으로 쓴다.
- 평가 기준이 바뀌어, 바뀐 기준으로 채점관을 다시 맞출 사람 점수가 필요할 때.
- LLM-as-a-judge가 사용자 시각과 맞는지 주기적으로 통계적으로 추정할 때. 사용자가 장면 표본을 채점하고 채점관 점수와의 일치도(예: Spearman, 최고 일치 비율)를 잰다. 비교 기준: 이전 Opus 채점관은 Spearman 0.39–0.45였다.
- 한 번에 끝낼 수 있을 만큼 묶음 수와 묶음 크기가 줄고, 채점 순서를 섞어 익숙함 효과를 잴 수 있을 때.
