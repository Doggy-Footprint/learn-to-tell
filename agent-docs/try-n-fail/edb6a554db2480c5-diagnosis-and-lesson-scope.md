## Revisit Condition
- 브라우저 진단: 대화 없이 진단해야 하는 호스트를 지원 범위에 넣을 때, 또는 브라우저 페이지에서 사용자가 카드마다 질문하고 agent의 답을 받은 뒤 같은 카드에 응답할 수 있게 될 때.
- 상황 카드: 카드에 나오는 개념이 모두 지식 map에 `quiz: pass`로 기록되어 있을 때, 또는 `result.md` 기준 최근 10편 중 3편 이상에서 사다리로 정한 학습 수준 아래 개념이 이해 확인 퀴즈에서 fail일 때.
- 범위 확인: 범위 알림을 받은 사용자가 범위를 바꿔 달라고 요청한 수업이 최근 10편 중 3편 이상일 때.
- 하한·상한: `result.md` 기준 최근 10편 중 3편 이상에서 이해 확인 퀴즈 fail이 나오고, 그 원인이 선행 개념 누락(하한 검토)이나 결정 변수 과다(상한 검토)로 기록될 때.
